# R 模式交付模板：诊断报告 / 修改报告

## 1. 诊断报告（R-advise，默认）

```
【题目】…  【标题（已定）】…  【模式】R-advise  【题干来源】用户提供 / 推断（待确认）

一、档位判断
档位区间：二类中（55–58），约 __–__ 分。依据：…
（估计，依据公开转载的上海细则；LLM 评分不稳定，仅作方向参考。）

二、硬数据（check_essay.py draft）
字数：含标点 __ / 不含标点 __；段落 __ 段；各段 [..]
扣分项预估：无标题 −_；字数缺额 −_（含标点口径）/ −_（不含标点口径）；标点错误 _ 处
口头禅/连接词开头段/破折号：…
错别字（人工通读）：第_段"__"应为"__"…

三、论据核验表
| 学生文中的说法 | 核验结果 | 来源 | 处理建议 |
|---|---|---|---|
| …（第_段） | 正确 / 张冠李戴 / 查无出处 / 数字有误 | URL | 保留 / 改为转述 / 删除 / 换为…（已核验） |

四、Top-3 问题（按 立意 > 结构 > 语言）
1. [立意] 位置：第_段第_句。问题：…。怎么改：…。示范句：…
2. [结构] …
3. [语言] …
次要问题（一行）：…

五、逐段批注（只写有问题的段）
第_段：…（保留的亮点：…）

六、升格路线
目标档位 → 需要的最低一级改动（L1/L2/L3/L4）及预期效果。

七、下一步
要我按 R-edit 直接改（标题不动，原句改动≤40%）吗？若缺口≥3环，说明局部改能做到的上限，并问是否转 R-rewrite。
```

## 2. 修改报告（R-edit / R-rewrite）

```
【模式】R-edit  【标题】未改（核对：一致）
改动幅度：old_sentences_changed_ratio=__（原句被改比例，上限0.4）；changed_ratio=__；新增句 __；逐段：第1段 unchanged；第2段 modified(0.7)；…
字数：改前 __ → 改后 __（含标点）；check_essay write：HARD 项 0

修改对照表
| 段 | 原句 | 新句 | 类别（硬伤/语言/论据/结构/立意） | 理由（一句） |
|---|---|---|---|---|

论据变化
| 动作 | 内容 | 账本行 | 状态 |
| 修正 | 原"…"改为转述 | E_ | paraphrase-only |
| 新增（≤1） | … | E_ | verified |

改前/改后档位：二类中(55–58) → 二类上(59–62)（估计；细分档：一类下63–64、二类上59–62、二类中55–58、二类下52–54）。
保留了什么：立意、标题、_个原有论据、原有的…（学生的亮点）
没动什么、为什么：…

新稿全文：（附在最后）
```
