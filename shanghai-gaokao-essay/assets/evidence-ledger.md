# 证据账本（Evidence Ledger）模板

用法：在 Step 2 提纲之后、Step 3 成文之前，把所有拟用的**外部事实**（人名、作品、事件、数字、引文、观点归属）逐行填入；evidence-bank 中的条目可直接引用其编号/名称，来源见 `assets/evidence-audit.json`，不必重搜。成稿后用 `python scripts/check_essay.py claims essay.md --ledger ledger.md` 抽取陈述清单并对账。

状态：`verified` 可用｜`paraphrase-only` 只准转述、不加引号｜`weakened` 表述已降到来源支持的范围｜`dropped` 查不实，删除。
来源等级：T1 官方/原始，可单独作依据｜T2 维基/主流媒体，需互证｜T3 自媒体/百度百科，仅作线索。

## 账本

| id | 类型 | 拟用表述（文中怎么写） | 来源 URL | 来源原文摘录（≤100字） | 等级 | 状态 | 用于哪段 | 备注（取材日期/口径/泛化风险） |
|---|---|---|---|---|---|---|---|---|
| E1 | 引文/事件/数字/作品归属/人物生平 | | | | T1/T2/T3 | | para ? | |

## 填写规则

0. **evidence-bank 的条目只写一行**：类型填"bank"，拟用表述写"bank:人名"（例：bank:梵高），来源写"evidence-bank（见 evidence-audit.json）"，摘录可省略，不必重搜；并遵守该条的〔直引〕/〔转述〕标记。
1. 一行只记一条可核验陈述；一个例子含多个事实（人、事、数、时）就拆成多行。
2. "拟用表述"写**文中将要出现的措辞**，摘录写**来源里的措辞**；两者强度不一致时，改拟用表述（状态记 `weakened`）。
3. 只有 T3 来源的行，状态不得为 `verified`。
4. `dropped` 的行保留在账本里（避免下次再用），但文中不得出现。
5. 引文类行必须记原文出处（篇名/章节）；转引类要记原作者。

**"外部案例≤2"的口径**：只数 evidence-bank 之外新增的案例；题干材料里自带的例子（如丑小鸭）不计；作者自拟的情境句（带引号的虚构场景/设问）不是引文，在账本里记"自拟，非引用"，不算新增案例，但**不要用引号包裹看起来像别人说的话**。

**`claims` 的局限**：脚本只能抽出书名、引号内文字、年份、数字、"某某说："以及内置名单里的人名；名单外的人名、事件、论点归属抽不到，会有少量误报。**抽取不完整，成稿后仍须通读补行**。

## 交稿闸门（逐项勾）

- [ ] `claims` 抽取的每个书名、引文、年份、数字、"某某说"，都能对应账本一行
- [ ] 无 `dropped` 行的内容残留在文中
- [ ] `paraphrase-only` 行在文中没有加引号
- [ ] 无只凭 T3 来源的事实
- [ ] 来源强度 ≥ 文中措辞强度（无泛化、无加码）
- [ ] 全文新增的外部案例 ≤2（evidence-bank 之外）
