# Step 1 审题拆解与立意生成

审题是上海卷的第一道分水岭。阅卷人30秒内判断"审题准不准、观点明不明"，审题偏差直接封顶52分。本步骤输出一份《审题结论》后才能进入提纲。

## 1. 题型识别

| 题型 | 识别特征 | 核心任务 |
|------|----------|----------|
| A 设问质疑型 | 题干以问句收尾，含绝对词："仅仅…吗""必定要…吗""是否意味着" | 质疑绝对化表述，给出有条件的否定/限定回答 |
| B 观点评价型 | "有人说…；也有人认为不尽如此/有人担忧，有人觉得正常" | 评价双方观点，各揭合理性与局限，给出整合立场 |
| C 概念阐释型 | "谈谈你对'X'的认识和思考"（X为单一概念） | 界定X→X的价值→X的异化/局限→重构"真正的X" |
| D 关系思辨型 | 材料呈现A与B两个概念的张力或作用关系 | 辨析A与B的真实关系（非简单对立，而是互构/条件/层次关系） |

混合题型按主导问法归类。例：2025"由专到传，必定要经过转吗"是A型，但内嵌三概念关系（D型思维辅助）。

## 2. 题干拆解操作（逐项执行）

第一，**抄录题干并切分成分**。把材料切成：背景陈述句 / 核心概念 / 逻辑连接词 / 最终问句。最终问句是全文必须直接回答的对象，一字不可绕开。

第二，**给每个核心概念做"维度切分"式工作定义**。不是给一句定义就完事，而是给每个核心概念划出2-4个可分别展开的维度（如："真"可分事实之真/伦理之真/精神之真；"命运"可分世俗境遇/精神境遇；"局限"可分禀赋/认知/时代三类），并排除常见的粗糙理解。维度划分的价值在于：它们直接生成本文分论点的骨架——一个维度撑起一层论证，全文因此不可能"平均用力"。检验标准：把维度列出来后问一句"每个维度能否各支撑一个分论点？"，不能则维度切错了。例："认可度"不等于"流行度"，前者含价值判断，后者只是传播事实；"预期"不是欲望本身，而是对结果的心理预支。

第三，**逐词扫描限定词与绝对词，各生成一个追问**。绝对词（"仅仅、必定、只有、凡事、总是"）是思辨的入口：题干说得越死，越要论证条件性；限定词（"任何时候、在当下、必须、往往、常常"）是高频被忽略的思辨发力点——"任何时候我们都得求真吗"的全部张力就在"任何时候"，"给时光以生命"若带"在当下"则论证必须带时代语境。对每个限定词生成一个显式追问（"'任何时候'成立吗？在公共事实领域与私人情感领域，要求应当不同吗？"），追问答案直接构成分论点。

第四，**显性化隐含前提**。题干往往埋着一个可以攻击的预设。"必定要经过转吗"预设了"转是专与传之间的唯一通道"；"仅仅是因为好奇心吗"预设了"好奇心是显而易见的动因"。找到预设，深掘层就有了靶子。

第五，**检查是否"定义之争"（定义层破题）**。若题干问的是"X是否可能""X与Y哪个更好""X是否意味着Y"，先追问：双方分歧是事实之争还是定义之争？若为定义之争，全文最有力的一步往往是重新定义关键概念使二难消解——"真正的共情不是完全抵达，而是持续靠近""掌控命运的实质是掌控自我"。重新定义必须比题干默认定义更有区分度，否则就是偷换概念。

第六，**确认问法类型对应的回答形态**。"是否/必定…吗"→回答必须是"不必然，但…"或"不仅仅，还有…"式的限定判断，不能含糊各打五十大板；"你怎么看"→必须给出明确的自家立场；"认识和思考"→必须超越描述，给出评价性论断。

## 3. 立意生成：三问法

完成拆解后，依次回答三个问题，答案合成中心论点：

1. **它为何合理？**（题干观点/现象回应了什么真实需求或现实焦虑）
2. **它何时失效/变质？**（隐含前提何时不成立；被推向极端后异化成什么）
3. **更完整的图景是什么？**（重新界定概念或关系，给出"真正的X"/"A与B的动态统一"）

中心论点=第三问的答案，写成一句含题干关键词的判断句。检验标准：这句话能否直接回答题干原始问句？能否被一个高三学生在考场上论证完成？（过于玄奥的立意反而危险，"中规中矩+思想深刻"意味着立意在主流认知带内，但比平均理解深一到两层。）

## 4. 立意深度的两个必备层次

阅卷反馈显示AI作文最常见的深度缺陷是"只从正面阐释"。63+作文必须包含：

**归因层（为什么）**：现象/观点背后的心理机制与社会机制。高分作文的归因是独立成段、分维度推进的完整因果链（"是什么→为什么→怎么办"），不是评价时顺带一提。两套词库交替使用：
- 向内归因（心理机制）：确定性需求、社会比较、认知吝啬（省力原则）、证实性偏差、损失厌恶、意义感需求、情感投射。
- 向外归因（社会机制）：算法与流量逻辑、优绩主义评价体系、消费主义与情感通货膨胀、加速社会与社会时钟、信息茧房、工具理性对生活的殖民、液态社会中的关系脆弱化。

归因让文章从"评价现象"上升为"解释现象"。检验标准：归因段删掉后，文章是否只剩观点复述？若是，说明归因层还没真正立起来。

**边界层（何时异化）**：观点被绝对化后的变形。两个要点：
- **对称双防**：不只防一个极端，而是同时防"X被绝对化"与"反X被滥用"两个方向的滑坡（如：绝对求真会沦为冷酷，以善之名放弃求真同样危险；突破局限异化为完美主义内耗，接受局限异化为躺平借口）。固定句式："但X一旦被绝对化，就会异化为Y；反过来，若以Z为由彻底放弃X，同样滑向另一个深渊。"
- **异化归因链**：异化分析要给出机制（现象→工具理性/流量逻辑→主体性让渡），而非罗列坏现象。固定句式思路："当X从手段变成目的，它就异化为Y"。例：降低预期→不思进取的借口；追求认可度→将自我定义权让渡给他人；极简生活→新的炫耀符号。

## 5. 常见审题陷阱（每条都有真实失分案例）

偷换概念：把"认可度"写成"他人的眼光"，把"想象"写成"梦想"——工作定义必须贯穿全文，不得中途漂移。

答非所问：题问"必定要经过转吗"，文章却大谈"如何写出传世文章"——每个分论点写完后自问：这段在回答题干的问句吗？

平均用力：三个分论点各谈一个方面，互不隶属，没有一以贯之的中心判断——分论点必须是中心论点的展开（递进或让步-立论关系），不是话题的并列罗列。

立场骑墙："既要…也要…"的和稀泥式结论——整合不等于折中，必须给出有倾向、有条件的明确判断（"不必然，但转的价值在于…真正决定传的，是…"）。

脱离材料自说自话：全文只在开头提一次材料，随后滑入预制的万能话题（奋斗、青春、坚持）——题干关键词必须在每个主体段出现。

## 6. 《审题结论》输出模板

进入Step 2前，先写出以下内容（工作笔记，不进正文）：

```
题型：A/B/C/D/E（E型先附比喻解码：本体=…，喻体=…，对应边界=…）
核心概念及维度切分：X＝…（不是…而是…）；维度1…／维度2…／维度3…
最终问句：…（原文抄录）
限定词追问：…（对"任何时候/在当下/仅仅"等各生成一个）
隐含前提：…
是否定义之争：是/否；若是，重新定义方案=…
中心论点（一句话，含题干关键词，直接回答问句）：…
归因层要点（向内+向外各至少一条）：…
边界层要点（对称双防：防X绝对化…；防反X滥用…）：…
```
