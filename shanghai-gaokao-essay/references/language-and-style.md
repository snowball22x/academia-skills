# Step 3 语言风格与句式规范

上海卷语言标准是"通顺流畅、有一定文采"，但文采服务于思想：以精确的概念辨析和清晰的逻辑推进立身，不堆砌辞藻。AI作文被点名的语言问题是"论文味重、文字生硬、共性鲜明个性平庸"，本文件给出去论文腔的具体规范。

## 1. 总体风格基线

书面语、学理化，但必须是"高水平高三学生"的声音，不是学术论文的声音。检验方法：通篇不出现"综上所述""笔者认为""本文认为""从…维度""赋能""底层逻辑"等论文/互联网黑话；不出现小标题、序号、分点；段落以过渡句自然衔接。句子长短相间：以中短句为主干，关键判断用短句单独成拍（"未必。""这才是问题的关键。"），长句用于归因分析。

## 2. 高价值句式库（辨析与思辨的语言载体）

概念界定式：「X不是…，而是…」「X并非…，恰恰是…」「与其说X是…，不如说它是…」

让步过渡式：「诚然，……但这并不意味着……」「这种担忧并非多余，只是它遮蔽了另一重事实——」「承认X的价值，不等于把X奉为唯一的尺度。」

设问推进式（代替生硬转折，全文1-2处）：「可是，X真的只能如此吗？」「问题在于：谁来定义这里的'好'？」

异化判断式：「当X从手段变成目的，它便悄然异化为Y。」「一旦…成为唯一标准，…反而成了它的牺牲品。」

归因分析式：「这背后，是…的心理在起作用」「与其归咎于个人，不如看到…的结构性力量」

升维整合式：「真正的X，是…与…的动态平衡」「二者并非此消彼长，而是互为条件：没有…的…是盲目的，没有…的…是空洞的。」

收束式：「由此观之，……」「归根结底，……」（"综上所述"的替代品）

## 3. 禁用与限用清单

| 类别 | 规则 |
|------|------|
| 禁用标题 | "破茧成蝶""扬帆起航""砥砺前行""不忘初心"及一切与题意仅有比喻性关联的烂俗意象 |
| 禁用结构词 | 小标题、"一、二、三"、"首先/其次/最后"式机械推进（可用"更进一步说""更值得警惕的是"替代） |
| 禁用论文腔 | "综上所述、笔者、本文、维度、赋能、闭环、抓手、底层逻辑、方法论层面" |
| 限用转折 | "然而/但是"全文合计≤3次；转折优先用让步句式或设问承接 |
| 限用排比 | 排例（三例连用）全文至多1处且须紧凑（每例≤15字）；排比句全文至多2处 |
| 限用感叹 | 感叹号全文≤1个；结尾禁止空喊口号（"让我们……吧！"） |

## 4. 标题拟法

标题必须让阅卷人预读到观点或核心概念关系，三种安全模式，按优先级：

1. **观点判断式**：直接把中心论点压缩为短句。例：《"转"非必经，价值为桥》《认可度之上，更有价值度》
2. **对举张力式**：呈现文章处理的核心张力。例：《于喧嚣处听惊雷》《在他人目光与自我尺度之间》
3. **概念重构式**：突出升维后的新概念。例：《真正的认可，经得起时间》

拟题后自检：标题中的题眼词是否会在正文出现至少两次？若标题用了意象（如"灯塔""惊雷"），正文必须对其展开阐释，否则换成朴素的观点式标题。宁可朴素准确，不可华丽空转。

## 5. 首段范式（≤150字）

结构：贴题现象一两句 → 概念界定 → 中心论点。示例（2024"认可度"题）：

> 点赞数、评分、销量榜——今天，我们比任何时代都更方便地用"认可度"为事物排定高下。然而认可度并非价值本身：它只是众人判断的聚合，是价值的回声而非价值的源头。以回声定高下，虽有其便利，却须警惕回声盖过声音本身。

要点：起笔的现象必须具体（点赞数、评分），三句内完成入题；首段即出现题干关键词；观点句有明确的判断和限定，不是"认可度很重要，我们要辩证看待"式的空转。

## 6. 例证写法（防"例证裸奔"）

标准单元＝观点句 → 例子（2-4句，剪裁到只剩与论点相关的侧面）→ 阐释（≥2句，回答"这个例子如何证明了观点"，并推进一层）。示例：

> 真正决定文章能否流传的，从来不是转发的热度，而是它与人心的深层共振。《赤壁赋》从未经过任何"转"的爆红，却在千年间被一代代失意者反复摩挲——因为它回答的是每个时代都会重逢的问题：有限的生命如何安顿于无限的宇宙。可见，"传"的通行证不是流量，而是对人类恒常困境的回应力。

反面示例（禁止）：连续罗列"屠呦呦……袁隆平……钟南山……"而无例后阐释；例子叙述超过4句变成讲故事。

## 7. 结尾范式（80-120字）

结构：方法论姿态（具体、可执行的认知姿态）→ 回扣题干关键词与标题 → 轻收。示例：

> 归根结底，认可度是参考系，不是审判席。既善用众人的目光校准自己，又为那些尚未被认可的价值保留一份耐心与敬意——如此，我们才不至于沦为认可度的囚徒，而能成为价值的发现者。

禁止：出现新例子新引文；"让我们携手……"式口号；只写一句话草草收场（阅卷反馈"没有明显的结尾"是AI典型失分点）。

## 8. 字数控制

目标900-1000字。逐段配额参考：首段120＋让步180＋深掘一200＋深掘二200＋升维180＋结语100≈980。写完逐段核对，不足时加厚"阐释"句而非增加例子；超长时先删例子叙述、再删排比。
