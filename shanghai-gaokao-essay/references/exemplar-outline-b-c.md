# 全流程示范补充：B型与C型（精简版）

本文件补充 exemplar-outline.md 未覆盖的两种题型，采用精简格式（审题结论+提纲+1-2个关键段落），密度对标exemplar-outline.md中的A型示范，供B/C型写作时参照标尺。

## B型示范：2021年上海卷「时间的沉淀」

### 真题

> 有人说，经过时间的沉淀，事物的价值才能被人们认识；也有人认为不尽如此。你怎么看？请写一篇文章，谈谈你的思考。

### Step 1 审题结论

```
题型：B 观点评价型（“有人说A，也有人认为不尽如此”），不可只评一方
A方核心主张：价值认知依赖时间的沉淀（需经沉淀方能被认识）
B方隐含主张：价值的被认识不必然依赖时间（存在即时被认识的价值，或时间反而遮蔽价值）
A方合理性：时间能过滤浮躁的即时评判，让价值脱离功利遮蔽显露本质
A方边界：把“需要时间”偷换成“时间本身产生价值”，忽视了主体认知能力才是关键变量
B方合理性：许多价值（救灾中的挺身而出、突破性的科学发现）在发生瞬间即被认识，无需等待
B方边界：若因此否定沉淀的意义，会陷入“即时即真”的浮躁认知，忽视了持续检验对深层价值的必要性
两方共享的错误预设：把“时间”本身当成价值的裁判者，而回避了“谁在认识、以何种眼光认识”这一更根本的问题
中心论点：价值的被认识，关键不在时间长短，而在认知主体能否穿透遮蔽——时间只是提供检验的机会，而非价值的来源
```

### Step 2 提纲

```
标题：《时间检验眼光，眼光成就价值》
第1段 引论（130字）：从“经典重估”“流量速朽”现象切入；界定“沉淀”＝主体持续检验而非被动等待；亮观点：价值的被认识关键在认知主体，时间只提供检验契机。
第2段 析A方（180字）：承认沉淀之功——浮躁的即时评判易被功利、偏见遮蔽；例：梵高画作生前无人问津，身后经艺术史反复审视方显价值；归因：短期评判往往受制于流行审美与既得利益。
第3段 析A方边界（180字）：但沉淀本身不产生价值，若无人持续以严肃眼光审视，再多时间也只是搁置；例：许多手稿、发现被埋没百年而非“沉淀出价值”，只是被遗忘。
第4段 析B方及其边界（200字）：另一方面，许多价值确在即时被认识——袁隆平杂交稻的意义在成果公布时便已明确；但若因此否定沉淀的意义，会滑向“流量即价值”的浮躁；例：热搜话题的速朽证明“被立刻看见”不等于“被真正认识”。
第5段 升维（180字）：真正决定价值能否被认识的，不是时间的长短，而是认知主体是否具备穿透遮蔽、持续追问的能力——时间只是把这种能力检验出来的机会而非源头。
第6段 结语（100字）：与其被动等待时间沉淀，不如主动锻造穿透表象的眼光；愿以此种眼光对待身边之人与事，而非只信奉“时间会证明一切”。
```

### 关键段落示范（首段+升维段）

> 首段：梵高的画作生前无人问津，多年后却拍出天价；某些热搜话题一夜爆红，转眼又无人记起。同样经过时间，一者显出价值，一者归于遗忘——可见“时间的沉淀”本身并不产生价值。价值能否被认识，关键不在时间长短，而在认知主体能否穿透遮蔽、持续审视；时间只是提供了检验的机会，而非价值的来源。

> 升维段：由此看来，与其说“时间沉淀出价值”，不如说“时间考验着认识者”。真正决定一件事物能否被认识的，从来是那双是否愿意持续追问、不受一时评判左右的眼光——沉淀的主体不是时间，而是人。

## C型示范：2024年上海卷「认可度」

### 真题

> 生活中，人们常用认可度判别事物，区分高下。请写一篇文章，谈谈你对“认可度”的认识和思考。

### Step 1 审题结论

```
题型：C 概念阐释型（“谈谈你对X的认识和思考”）
工作定义（排除式）：认可度不是被认可的人数多少，而是……（留待第4-5段回答，先给初步界定）——他人评价的聚合结果，一种社会性的价值反馈
认可度的价值（为何依赖它）：个体难以脱离社会性存在，他人认可提供确认与归属，也是效率化的判别捷径（无需逐一深究即可参考多数人的选择）
认可度的局限/异化：把“认可度高”直接等同于“价值高”，会导致以迎合代替坚持、以流量代替深度，出现“劣币驱�率良币”（哗众取宠比真正优质更易获得认可）
真正的认可度（重构）：不是被多数人喜欢的程度，而是经得起理性审视、能穿越时间与立场差异的价值共识——高认可度应是结果而非追求的目标
主体应如何相处：既不盲从认可度也不刻意反其道而行，而是以认可度为参考、以自身判断力为锚点
中心论点：认可度是价值的参考信号，而非价值本身；真正值得追求的不是认可度的高低，而是让认可度经得起时间与理性的审视
```

### Step 2 提纲

```
标题：《莫为认可所困，但求价值可鉴》
第1段 引论（130字）：从“流量至上”“数据即价值”现象切入；界定认可度＝他人评价的聚合反馈；亮观点：认可度是参考信号，不是价值本身。
第2段 认可度的价值（180字）：承认认可度确有其功——归因：人是社会性存在，他人认可提供归属与效率化判别；例：学术论文的同行评议本质是一种建制化的认可度机制，帮助非专业者辨识可信度。
第3段 认可度的局限（200字）：但认可度的高低易受传播机制左右，与真实价值脱钩；例：短视频平台上，猎奇内容常比严肃创作获得更高认可度，认可度成了流量算法的产物而非价值的证明。
第4段 异化分析（200字）：更值得警惕的是，当追求认可度本身成为目的，创作与判断便开始迎合多数、放弃独立立场——“劣币驱逐良币”由此发生：哗众取宠比深耕细作更易被认可。
第5段 升维（180字）：真正值得追求的认可度，不是当下多数人的即时反馈，而是经得起理性审视、能穿越时间检验的价值共识——认可度应是价值自然产生的结果，而非刻意追逐的目标。
第6段 结语（100字）：面对纷杂的评价场域，我们既不必因无人认可而自我怀疑，也不可为博取认可而放弃判断；愿以自身的价值判断力为锚，让认可度成为水到渠成的印证，而非奔逐的终点。
```

### 关键段落示范（异化段）

> 更值得警惕的是，当追求认可度本身成为目的，创作与判断便开始悄然让位于迎合：为博点赞而制造噱头，为避免争议而回避真问题，独立的判断力在“怕不被认可”的焦虑中逐渐让位。于是“劣币驱逐良币”的现象由此而生——哗众取宠远比深耕细作更容易换来即时的认可度，而后者所需要的时间与耐心，恰恰是流量逻辑最不愿等待的。

## 质量标尺说明

对照本文件自检：B型是否真的对两方各做了“合理性→边界”的小循环分析（而非只批评一方）；C型的概念界定是否在第1段和第4-5段形成呼应（先给初步界定，后给重构定义，而非两次重复同一句话）。两种题型均须完成归因层与边界/异化层，参照SKILL.md九大通病表逐条自检。
