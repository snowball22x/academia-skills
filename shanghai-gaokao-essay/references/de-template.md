# Step 3.5 去模板化（成稿后、自查前）

目的：让文章读起来是"一个人在想这个问题"，而不是"一个 skill 在套这个流程"。**结构不动，只动表面。**

## 0. 为什么需要这一步（证据）

- 阅卷老师评 11 个大模型的同题作文（21世纪经济报道，2026-06-08，全国一卷；偏叙事题，迁移到上海议论文是类比而非定论）：一眼能认出的是排比、金句、破折号，以及"一路正确"——没有犹豫、矛盾和张力；"个人→社会→时代→青年使命"的固定走向；选词都在安全区；还有虚构素材。
- 本 skill 自己的基线测试（旧版，5 道题各写一篇，见 `tests/baseline_v1/`，用 `tests/eval_convergence.py` 复现）：第2段 5/5 以"诚然"开头，第5段 5/5 以"由此看来"开头，第4段 4/5 以"更值得警惕的是"开头，结尾 4/5 以"归根结底"开头；"诚然"在 5/5 篇出现。这是 skill 的句式库和范文被逐字复刻的结果，不是模型偶然。
- 阅卷对"中规中矩 + 思想深刻"的要求并不禁止规整结构；被点名的是**措辞层的雷同**和**缺少真实张力**。所以只改措辞层。

## 1. 不要动的（得分机制）

五段骨架；让步段与"有限成立"收束句；归因层与边界层；对称双防；升维段的明确倾向；结语回扣标题题眼；概念界定（含"不是……而是……"的排除式定义）；每例后≥2句阐释。去模板化不得削弱其中任何一项。

## 2. 要改的

### 2.1 口头禅预算
下列短语是 skill 以前"推荐"的，现在**每篇每个至多出现一次**，且同一对话里写第二篇时换一种说法。上限数字以 `assets/lint-rules.json` 为准：
`更值得警惕的是` `诚然` `归根结底` `由此观之` `由此看来` `渡口`；另有 `不是`≤6、`真正的`≤3、`异化`≤3。
"异化""真正的X"是合法概念，但一篇里反复出现就成了口头禅：第二次起改用具体描述（"被当成目的"、"成熟的X"、"站得住的X"）。

### 2.2 段首多样性
- 六个段落里，**以连接词开头的段落≤3个**（连接词＝诚然/可是/然而/于是/由此看来/归根结底/更……的是 等）。其余段落直接以论点句、场景句、设问或一个具体细节开头。
- **不要让第2、4、5、6段都套同一格式**（让步—转折—升维—收束各一个固定开头词，是这套流程最容易露出的流水线痕迹）。功能必须有，开头词不必有。
- 让步、异化、升维、收束四个动作，每个动作从下列备选里**每篇选一种，或自创，且不得与上一篇相同**：
  - 让步：这种看法并非无稽｜先看它站得住的一面｜不能否认……｜直接陈述其合理之处，不加连接词
  - 转入边界：问题出在……｜但这只在……的前提下成立｜它的麻烦在于……
  - 异化：当X从手段变成目的，……｜一旦X成了唯一的尺子，……｜X被绝对化之后，……（只写机制，不要套"更值得警惕"）
  - 升维：把……与……放在一起看｜换一个角度……｜于是X应当重新定义为……
  - 收束：说到底｜落到实处｜这样看｜直接陈述结论
  这些不是新模板，只是避免整篇靠同一个词推进。

### 2.3 标点与节奏
- 破折号全文≤2。能用逗号、冒号、句号的不用破折号。
- 金句≤2。判断标准：这句话适合被截图转发吗？若是，要么重写成带限定和理由的判断，要么承担一个论证步骤；孤零零的格言不要。
- 排比≤1（原规则不变）；同一首字连续三个以上分句＝排比。
- 句长要有起伏：每段至少一个短句（≤12字）下判断，至少一个长句讲道理；全文句长标准差太小脚本会提示。

### 2.4 "一路正确"的解药（议论文版）
边界层之外，再写**一处本文立场自身的代价或失效条件**：这个主张在什么情形下不成立，或者坚持它要付出什么。不是骑墙，也不是"既要又要"——立场不变，但给它加上真实的条件。避免"我终于明白""由此我们懂得"式的顿悟收尾。

### 2.5 具体化
- 每个主体段至少一个能被核验的具体锚点：人、作品、事件、数字或一个看得见的场景；锚点必须在证据账本里。
- 不用无信息的背景句开头："在当今社会""随着……的发展""在这个飞速发展的时代"。
- 抽象名词（时代、精神、价值、意义）不要连续两句做主语。
- "借权威"禁用：有学者指出、专家认为——要么署名并核验，要么不写。
- 句尾补充式拔高禁用："……彰显了……""……体现了对……的追求"。升华必须由前文论证兑现，不能靠结尾贴标签（周宏点名的"伪崇高"）。

## 3. 保真约束（借自 humanizer-zh 的核心原则）

去模板化是**措辞改写**，不是内容改写：
1. 不改变论点、论据、否定、限定、归因和确定程度（"可能"不能改成"必然"，"有人认为"不能改成"事实是"）。
2. 不新增论据；账本里的核验状态不因改写而改变。
3. 不为了"像人"而硬塞口语词、感叹或编造的亲身经历。没问题的句子保持原样。
4. 改完对照原稿，逐句确认没有丢掉信息，也没有多出信息。

## 4. 流程

```
1. 有代码执行：python scripts/check_essay.py write essay.md --keywords 题眼1,题眼2
   无代码执行：按本文件第2节人工自查（口头禅、段首、破折号、金句、句长）
2. 只改被标出的句子和段首；每轮改完重跑；最多2轮。
3. 对抗性追问：把全文里本题独有的关键词全部删掉，某一段还能原样套到别的作文题上吗？能，说明论证空泛，回 Step 2 补具体内容，而不是继续润色。
4. 通过后再进入 Step 4 的自查清单与分档自评。
```
