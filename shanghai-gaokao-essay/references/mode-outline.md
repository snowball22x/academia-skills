# O 模式：解题、brainstorm 与提纲（不成文）

适用：用户给了题目，要的是**审题、立意、思路、提纲、素材**，而不是一篇文章；或者带着自己的立意来问"这个角度行不行"。本模式的终点是一份可交付的提纲方案，**不写成文段落**（仅允许首段、结尾段各给 ≤1 句示范句）。结束时问用户是否据此成文，若是则转 W 模式，沿用本模式的审题结论、提纲和证据账本，不重做。

两个深度档，用户可指定，默认研讨版：
- **考场版**：O1 审题结论 + 推荐立意 + 6 行提纲 + 素材位（素材位直接写 evidence-bank 条目，如"bank:梵高"，附一行极简素材表）。离线可用，不依赖搜索；总长度以**不超过约40行**为准（一屏）。
- **研讨版**：完整 O0–O8。

## 流程

```
O0 识别       查 assets/past-prompts.md：是否上海卷历年真题？是 → 抓取该年上海市教育考试院"专家点评"，校准审题水位（search-enhancement.md 动作B）。模拟题/二模无官方点评：跳过，用动作A校准概念。若题目就是 exemplar-outline.md 里的示范题，**先独立发散，再对照示范**，避免被锚定
O1 审题结论   按 references/prompt-analysis.md 的模板：题型(A-E，E型先做比喻解码)、概念工作定义与维度切分、最终问句、限定词追问、隐含前提、是否定义之争
O2 发散       见下"发散工具箱"
O3 立意候选   收敛为 3 个，每个一句话中心论点（含题干关键词，直接回答最终问句）：1个稳妥、1个更深、1个有风险
O4 评估       见下"评估表"。给出推荐与理由
O5 提纲       仅对推荐立意展开：逐段 论点句草稿 + 论证动作 + 素材位 + 字数配额
O6 素材       按素材位搜索核验，填证据账本；交付"主选 + 备选"，每条标来源、可直引/仅转述
O7 避坑       本题特有的误读与陷阱 2-3 条
O8 收尾       询问是否据此成文
```

## 发散工具箱（O2）

1. **概念多义展开**：对每个核心概念列出 2–4 种合法读法。上海市教育考试院每年的专家点评就是这样做的：2025 年"专转传"题，专家把"专"展开为专业文章/不同领域的专业成果，"转"展开为新媒体转发/口传文字等通俗化传播/知识在日常生活中的普及，"传"展开为传世文章/经时间检验的智慧结晶，再追问"专是否必须借转才能彰显价值"。每种读法都要说明它会把立意引向哪里。
2. **限定词与绝对词追问**：对"仅仅/必定/任何时候/在当下"等逐个生成追问，答案就是分论点的雏形。
3. **关系模型**：A 与 B 之间是互构、条件（必要/充分）还是层次？
4. **正反情形对照**：什么情形下题干观点成立？什么情形下失效？被推向极端会异化成什么？（对应归因层、边界层）
5. **视角切换**：个人 / 社会 / 时代，三个尺度各问一遍，看哪个尺度最能压出新意又仍在考场能论完的范围内。
6. **立意空间对照**：若是真题，把官方点评列出的立意空间画成一张小图，标出自己的候选落在哪里（"中规中矩"= 落在主流认知带内；"思想深刻"= 归因与边界比点评多一层）。

## 评估表（O4）

三个候选各按五项打 1–5 分，并用一句话写依据。**这是启发式的比较工具，用来在候选之间做取舍，不预测考场得分**。

| 维度 | 看什么 |
|---|---|
| 扣题度 | 能否直接回答最终问句？题干关键词是否贯穿？有无脱离材料 |
| 深度 | 是否同时具备归因层与边界层？整合段有无明确倾向（非"既要又要"） |
| 可论证性 | 高三学生 900 字内能否论完？是否过于玄奥 |
| 素材可得性 | evidence-bank 或可核验的近期素材是否支撑每个论证段 |
| 低风险得分 | 偏题、陈词滥调、立场骑墙、只能写成泛论的风险越低，得分越高（5＝几乎无风险，1＝高风险） |

推荐规则：总分最高且扣题度≥4 的候选为推荐。**平局**（总分相同，或差距≤1分）时，选深度分高者，前提是其可论证性≥3；否则选稳妥者，并在交付里把另一个列为"备选，请用户定"。若"更深"的候选可论证性≤2，不推荐，只作备选并说明原因。**吸收规则**：推荐立意可以吸收落选候选中的一句话或一个维度（例如把 B 的三维度拆给 A 的第3–5段），但不得缝合成两个中心论点——全文仍只有一个中心论点。

## 提纲格式（O5）

沿用 `references/structure-and-outline.md` 的逐段提纲模板，每段补三项：
- **论点句草稿**（一句完整判断，含题干关键词；这是提纲不是正文，可以不润色。与"示范句"的界线：论点句草稿每段都写，是判断本身；示范句是润色过的成文句，全程只允许首段、结尾段各一句）
- **论证动作**：让步 / 驳隐含前提 / 归因 / 边界（对称双防）/ 升维 / 回扣
- **素材位**：指向账本里的某一行（E1、E2……）或写"纯思辨，无素材"

最后给出字数配额（各段之和 900–1000）。归因与对称双防挤在同一段（≈200字）写不下时，可以拆成两段（深掘二、深掘三），总段数仍在 6–8 段内。

素材状态与"可直引"的关系：`verified` 的古文/一手文献引文＝可直引；`verified` 的事件、数字不涉及引号；外国学者的观点、概念一律 `paraphrase-only`，不可直引。

## 立意打磨子模式（用户带着自己的立意来）

1. 先**复述**用户的立意，确认理解无误。
2. 判断是否扣题：对照 O1 的审题结论，指出贴合处与偏离处（偏离要具体到哪个词）。
3. 用 O4 的同一评估表给这个立意打分。
4. 给出升级方向：缺归因补什么、缺边界补什么、哪里可以更具体；再给 1–2 个替代立意供对比。
5. **不替换用户的立意**，除非用户要求。

## 与 W 模式的关系

O 的 O1/O5/O6 产物就是 W 的 Step 1/Step 2/账本。O 模式没有成稿，`claims` 对提纲噪声大，**素材对账手工完成**（逐个素材位对应账本行）；evidence-bank 条目写成"bank:人名"，来源见 evidence-audit.json，不必逐条载入。从 O 转 W 时直接进入 Step 3，不重复审题；只需补跑 Step 3.5 和 Step 4。

## 自检（交付前）

- [ ] 3 个立意候选彼此不是同一立意的改写；每个都含题干关键词并直接回答最终问句
- [ ] 推荐有评估表支撑，且写明了"启发式比较，不预测得分"
- [ ] 提纲每段都有论点句草稿、论证动作、素材位
- [ ] 素材清单每条带来源与"可直引/仅转述"标记；账本外没有专名、数字、引文
- [ ] 没有成文段落（首尾各 ≤1 句示范句除外）
- [ ] 考场版不超过一屏
