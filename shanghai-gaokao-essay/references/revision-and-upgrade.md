# 修改升格：诊断已有草稿

用途：当用户提供的是一篇已经写好的作文（草稿/旧稿），要求"修改""升格""看看哪里有问题""帮我改到一类卷"等，使用本文件的流程，而不是套用SKILL.md的Step 1-3从头重写一篇新文章。目标是精准诊断+局部升格，尽量保留原文已经达标的构思与语言个性，而不是替用户重写。

## 0. 先做什么：定位当前档位

通读一遍全文，对照SKILL.md《九大AI写作通病表》和《交稿前分档自评表》（立意深度/结构完整度/语言规范度三维打分），快速判断草稿目前大致落在哪个区间：

- **三类卷（<50分）常见信号**：跑题或审题严重偏移、无中心论点、记叙文/散文化、字数严重不足
- **二类卷（50-61分）常见信号**：审题基本对但立意浅、结构骨架不全（缺让步段或缺深掘/异化段）、例证堆砌无阐释、语言基本通顺但平淡
- **一类下/二类上边缘（58-64分）常见信号**：结构齐全但某一层（归因/边界/升维）薄弱、个别引证存疑、结尾口号化

先给用户一句话诊断结论（"目前大致落在XX分档，主要问题是XX"），再进入下面的具体诊断。

## 1. 诊断清单（逐条对照原文标注"有/无/弱"）

1. 中心论点是否在首段末清晰出现，是否直接回应题干的原始问法？
2. 是否只有一个中心论点，分论点是否都服务于它（而非并列话题）？
3. 是否完成概念界定，是否用了排除式定义（"不是A，而是B"）？
4. 是否有让步段？让步是否只是一句敷衍，还是真正说明了对方合理性的机制？
5. 是否有深掘/异化层（该观点被推向极端后的问题）？
6. 例证后是否有≥2句阐释？是否存在三例连排超过一处？
7. 引文是否存疑（张冠李戴、编造数据、模糊出处）？
8. 结尾是否回扣题干关键词，是否落在具体认知姿态而非口号？
9. 是否有小标题、序号分点、记叙文化倾向？
10. "然而/但是"是否滥用（>3次）？

## 2. 升格优先级排序

不要平均用力地"每条都改一点"。按以下优先级修复，优先解决能带来分档跳跃的问题：

- **第一优先：审题/中心论点问题**（对照第1、2条）——这类问题不修，后面改什么都没用，必要时需要重新定位论点、调整全文重心。
- **第二优先：结构缺层**（对照第3、4、5条）——通常是二类卷和一类卷的分水岭，缺让步段或缺异化层，需要新增1-2个完整段落而非小修小补。
- **第三优先：例证与引用问题**（对照第6、7条）——直接影响是否被扣"引用不实"，必须逐一核验或删除存疑内容（核验方法见 references/search-enhancement.md）。
- **第四优先：语言与格式微调**（对照第8、9、10条）——锦上添花，通常不能单独解决分档问题。

给用户的修改建议必须标注"这一条属于第几优先级""预期能带来多大档位提升"，不要笼统地说"建议修改"。

## 3. 输出形式

默认按段落定位给出修改建议，格式：

```
【第X段，原文："……"】
问题：对照第N条，属于第M优先级
建议：具体怎么改（给出改写后的示例句，而非只说"要更深刻"）
```

除非用户明确要求"重写全文"，否则不要输出整篇替换稿；默认只输出"诊断结论 + 分段修改建议 + 若干示例改写句"。若用户确实要求重写，则在完成诊断后，只重写被标记为"无/弱"的段落，保留原文中已经达标的段落原样，不做无意义的推倒重来。

## 4. 常见误诊陷阱

- 不要把"语言朴素"误诊为"语言差"——朴素但准确、有阐释的语言不需要堆砌辞采去"修饰"。
- 不要把"篇幅短的深掘段"误诊为"没有深掘"——深掘段哪怕只有80字，只要完成了机制分析（"从手段异化为目的"），就算达标，字数不是判断深度的唯一标准。
- 不要因为个别句子读起来"不够高级"就大改语言而忽略更致命的结构缺失——严格按第2节的优先级顺序处理，先治大病再治小病。
