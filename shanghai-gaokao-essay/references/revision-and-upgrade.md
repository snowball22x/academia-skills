# R 模式：修改升格（题目 + 确定标题 + 已写好的作文）

## 适用场景与总原则

用户给了题目、**一个已定的标题**和一篇已经写完的上海高考作文（自己写的、AI写的、旧稿），要求"看看哪里要改""怎么提分""升格""直接帮我改"。不走 SKILL.md 的新写流程，走本文件。

三条总原则：
1. **先诊断，再决定动多大手术**；能局部改的不整篇重写。用户需要学到差距在哪，不是拿到一篇被替换掉的新文章。
2. **标题和作者的声音是用户的**：标题默认不动；不把学生的句子统一改成"AI 腔"或论文腔。
3. **事实错误必须指出**：学生引的名言、事例、数字要核验；错的是最稳妥可证的提分点。

## 工作流

```
R0 输入校验   题目(必)、标题(固定，除非用户说可改)、正文(必)。缺题目 → 先问；给不出则推断题干，报告里标"推断"
R1 模式选择   默认 R-advise；用户明确说"直接改/帮我改好" → R-edit；"重写/推倒重来" → R-rewrite
              不确定时一句话问："要我只指出问题与改法，还是直接给改稿？"
R2 机检       有代码执行：python scripts/check_essay.py draft essay.md --title "<固定标题>" --keywords 题眼1,题眼2
              （字数两种口径、扣分项预估、标点配对、口头禅、逐段统计表）；无代码执行：人工核对同样项目
R3 核验       python scripts/check_essay.py claims essay.md 抽取学生文中的专名/引文/数字/书名 → 逐条搜索核验（search-enhancement.md 第3节门槛），记入账本；错的标出并给替换方案
R4 诊断       通读定档 → 九大通病命中 → 五段骨架缺环 → 语言与格式（下文 R-a/R-b/R-c）
R5 优先级     只列 Top-3 影响档位的问题，按"立意 > 结构 > 语言"排序；其余合并为"次要问题"一行。不面面俱到
R6 产出       按所选模式（见下）
R7 复检       R-edit/R-rewrite：再跑 check_essay.py + diff；自查清单；给改前/改后档位对照
```

## 诊断方法

### R-a 通读定档：给档位区间（不给单点分）

通读全文一遍，凭整体印象回答：
1. 30秒读完首段，能否看出"审题准、观点明"？—— 决定是否已越过及格线进入二类。
2. 中间是观点集中，还是话题分散、平均用力？—— 决定二类上还是二类中。
3. 结尾是否收住了，还是草草收尾或喊口号？

给出**档位区间并写明依据**，如"二类中，约 56–59：首段观点明确，但全文缺边界层"。依据：公开转载的上海议论类细则——一类卷 63–70、二类 52–62、三类 39–51、四类 21–38；官方原文以考试院公布为准。这是估计，不是评分；明说"LLM 打分不稳定，仅作方向参考"，不要给 61.5 这样的精确分。

### R-b 逐项诊断：九大通病表

把 SKILL.md《必须规避的九大AI写作通病》表当诊断清单，只列**命中**项，并定位到段/句；不要对未命中项逐条说"没问题"：

```
命中 #1 审题浅：第1段观点句未复现题干关键词"XX"，偏离了原问法
命中 #6 案例堆砌：第3段连续三个例子（A、B、C）均无阐释句，属于排例超限
```

避免"结构可以更严谨"这类无法执行的评价；每条要让用户知道改哪一句、加哪一句。

### R-c 立意与结构：对照五段骨架找缺环

对照 references/structure-and-outline.md：
- 缺概念界定 → 大概率"审题浅""立论空泛"。
- 缺让步段 → 单向度赞美/批判，读起来武断。
- 有深掘但没有异化/边界分析 → 停留在正面阐释，最常见的二类卷症状。
- 缺整合/升维段，直接从批判跳到结语 → 虎头蛇尾。

每处缺失给出**应插入在第几段之后**、写什么，以及一两句起笔示范。

### R-d 语言与格式

对照 language-and-style.md 与九大通病第3、4、5、9条：标题是否空泛（用户已定标题则只报告不改）、是否有小标题、首尾是否失衡、"然而/但是"是否超限。再对照 de-template.md 检查口头禅与段首连接词；**对学生自己写的稿子，只标出确实空泛或重复的句子，不为"去 AI 味"而改动通顺的原句。**

### R-e 扣分项（最稳的提分点）

依据上海细则公开转载的"扣分项评定"（2018/2021/2023 一致）：错别字 1 个 −1（重复不计，上限 −5）；标点错误超过 3 处酌情扣分；不足字数每少 50 字 −1；无标题 −2。脚本负责字数、标题、标点配对；**错别字不由脚本判定，由你通读时找**，列出具体字词。

## 三个产出模式

| 模式 | 做什么 | 改动上限 | 交付 |
|---|---|---|---|
| **R-advise**（默认） | 不动原文；每个问题定位到段/句，附一两句示范改法 | 0 | 诊断报告（见 assets/revision-report.md）：档位 → Top-3 → 逐段批注 → 论据核验表 → 扣分项 → 下一步 |
| **R-edit** | 在保留立意、标题、已有论据、段落顺序的前提下局部升格 | 默认 ≤40% 文本变更，用 `check_essay.py diff old.md new.md` 实测；超出须向用户说明为什么 | 改后全文 + 修改对照表（原句 → 新句 → 理由类别：硬伤/语言/论据/结构/立意）+ 报告 |
| **R-rewrite** | 保留题意与标题，按 W 流程重写 | 无 | 先给诊断（几行即可），再给新稿，说明保留了什么、改了什么 |

只有以下情况才主动转 R-rewrite：用户明确要求；或原文审题错误（跑题）/ 五段骨架缺 3 环以上，局部修改已不足以成立——此时先征得同意。

### R-edit 硬规则

- **标题不动**。若标题确实拖后腿，只在报告里附 1–2 个备选，不替换；`draft --title` 会核对标题字面是否一致。
- **声音保护**：沿用学生的句长习惯与用词层次；不把口语化的地方统一改成论文腔；不替学生添加亲身经历、数据或情绪。
- **论据优先深化，不优先换例**：原例子没有事实错误且位置合适，就保留并补阐释。确需新增论据时 ≤1 个，必须过账本并在对照表中标"新增"。
- **事实错误必须改**：账本核验为 wrong/unverifiable/dropped 的引文或事例，改为转述、删除或换成已核验的替代，并在对照表单列"硬伤"类。
- **按梯度升格，只做到能把档位推上去的最低一级**：L1 硬伤（错别字、标点、病句、事实）→ L2 句段（归因/边界/升维句）→ L3 结构（补缺环、调段序）→ L4 立意重构。用户要求更高才升级。
- 稿件若有明显 AI 腔（口头禅堆叠、排比金句），在 L2 阶段做局部替换，不整篇重写；遵守 de-template.md 第3节的保真约束（不改论点、论据、限定、归因）。
- **引导式选项**：用户若说"想学会怎么改"，R-advise 改用引导修改型提问（"这一段删掉后，论证还成立吗？""这个例子能证明你的哪一句话？"），而不是直接给替换句。

### R-edit 复检

1. `check_essay.py write new.md --keywords …`（字数区间、HARD 项为零）。
2. `check_essay.py diff old.md new.md`：标题未变；`changed_ratio ≤ 0.4`；逐段状态表里没有意外的整段重写。
3. 新增论据均在账本；`claims` 对账通过。
4. 回读：改后的句子是否仍像同一个人写的？有没有把原本有个性的表达磨平？

## 评分口径

- 只给档位区间与依据；不承诺分数。
- 研究上，LLM 评分与人评分的一致性取决于是否给了锚点作文，偏差方向并不一致；因此结论必须带不确定性。
- 需要更稳的档位判断时，建议用户提供 2–3 篇已知得分的同题作文作为锚点（可选）。

## 常见反模式（避免）

- 一上来就大段重写、绕过诊断——用户学不到东西，也可能改坏原本不错的地方。
- 笼统评价（"语言不错，结构一般，加油"），不具体到段落和句子。
- 用新例子替换原有例子，除非原例子有事实错误或位置不当。
- 把结构、语言层面的小问题当成决定分档的主因——立意深度不够，语言再华丽也压不上一类。
- 为了"让文章更完美"而超出用户要求的改动幅度；用户要局部改，就不要重写。
- 给出精确到小数点的分数。
