# Step 2 结构与提纲

结构是62+作文的安全网。上海卷阅卷对"结构严谨"的要求，落实为：段落功能清晰、段间逻辑显性、首尾均衡。本文件给出思辨五段骨架的逐段写法与四种题型的变体，输出一份逐段提纲后才能进入Step 3。

## 1. 思辨五段骨架（6-8个自然段，900-1000字）

### 第一段：引论（100-150字）
三个动作一气呵成：现象切入（一两句，从题干材料或贴近材料的时代现象起笔，禁止大而无当的"在这个飞速发展的时代"）→ 概念界定（对核心概念下工作定义，优先用排除式："X不是…，而是…"）→ 亮明中心论点（直接回答题干问句，复现题干关键词）。首段写完的检验：阅卷人只读这一段，能否准确说出你的题型判断和立场？

### 第二段：正论/让步段（150-200字）
承认题干观点（或被质疑一方）的合理性。写法：先陈述该观点成立的典型情形，再归因——它回应了什么真实需求（心理机制或社会机制），可辅以一个简例。此段的功能是展示思维公允，为后文的批判性分析赢得信任。常用起笔："诚然，……""这种看法并非无稽。"

### 第三、四段：驳论/深掘段（250-350字，全文重心）
揭示前述观点的局限，两段常为递进关系。第三段攻击隐含前提或指出适用边界（"必定要经过转吗？未必。当……时，专可以直接抵达传"）；第四段做异化分析（"更值得警惕的是，当X被奉为唯一标准，它便从手段异化为目的……"）。此处必须完成归因层与边界层（见prompt-analysis.md第4节）。每段例子不超过2个，例后至少两句阐释把例子拉回论点。

### 第五段：整合/升维段（150-200字）
重新界定概念，给出"真正的/成熟的/健康的X"，把二元张力转化为动态统一（互构、条件、层次、螺旋上升）。这是立意深度的兑现处，也是与二类卷拉开差距的段落。写法示例："由此看来，真正的认可度不应是他人目光的简单加总，而是经得起自我审视与时间检验的价值共识。"注意：整合必须有明确倾向，不是"既要也要"的折中。

### 第六段：结语（80-120字）
方法论收束（我们应以何种姿态面对X，落在具体认知姿态而非口号）→ 回扣题干关键词与标题题眼 → 可轻触时代与青年身份收束。禁止引入新概念、新例子。必须让阅卷人明确感到"文章收住了"。

## 2. 四种题型的骨架变体

**A 设问质疑型**（"必定/仅仅…吗"）：第一段即给出限定性回答（"未必""不仅仅"）；第二段让步（承认题干路径的常态性与合理性）；第三段举出反例情形并说明其成立条件；第四段深掘——追问题干真正关心的问题（"必定要经过转吗"背后是"传的本质由什么决定"），完成概念升维；第五段整合出有条件的判断；结语收束。

**B 观点评价型**（"有人说A，也有人说B"）：不可只评一方。第二段析A方合理性及其局限，第三段析B方合理性及其局限（两段内部各自"合理性→边界"小循环），第四段找出双方共享的深层问题或错误预设，第五段给出超越两方的整合立场。注意立场必须有倾向，明确回答"你怎么看"。

**C 概念阐释型**（"谈谈你对X的认识"）：结构为"界定X→X的价值（人们为何依赖X）→X的局限与异化（X失效、被滥用的情形）→重构真正的X→我们应如何与X相处"。此题型最忌泛泛而谈，工作定义的区分度决定全文高度。

**D 关系思辨型**（A与B）：先分别界定A与B，指出常识把二者对立/割裂的粗糙之处；再论证真实关系——常用三种模型：互构（A塑造B，B反作用于A）、条件（A是B的前提但不充分）、层次（表层对立，深层统一）；异化段写"只有A没有B"或"以A吞噬B"的后果；整合段给出动态平衡的姿态。

## 3. 分论点设计规则

分论点之间必须是**递进**（现象→原因→本质；个人→社会→存在）或**让步-立论**（诚然合理→但有边界→真正的X是）关系，禁止并列式三条腿（"X有利于个人/社会/国家"是典型的平均用力，直接掉二类中）。每个分论点写成完整判断句放在段首（观点句前置），且必须含题干关键词或其工作定义中的核心语汇。

## 4. 提纲输出模板

进入Step 3前，先写出逐段提纲（工作笔记，不进正文）：

```
标题：…
第1段 引论：切入现象…；界定X＝…；中心论点：…
第2段 让步：承认…合理，因为它回应了…（例：…）
第3段 深掘一：但其前提/边界在于…（例：…）
第4段 深掘二/异化：当…被绝对化，便异化为…（归因：…）
第5段 升维：真正的X是…（重新定义）
第6段 结语：应以…姿态…；回扣"…"
```

写提纲时同步分配字数（各段字数之和落在900-1000），并为每段挑好引证（从evidence-bank.md选，每篇全文引证总量：名言1-2处、事例2-3个、古诗文0-2处，宁缺毋滥）。
