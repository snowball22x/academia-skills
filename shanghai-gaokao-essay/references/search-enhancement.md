# 网络搜索增强（有搜索能力时使用）

若执行环境具备网络搜索能力，按本文件在写作流程的对应节点嵌入搜索动作。核心原则：**搜索服务于论证，不服务于堆料**。搜索的目的只有四个——理解陌生题干、校准立意水位、获取精准素材、验证引用真伪。每个目的对应固定的搜索时机与落实方法。无搜索能力时跳过本文件，写作流程完全不受影响（evidence-bank.md保证了离线可用的底线）。

搜索预算纪律：全流程搜索控制在3-6次以内，每次带着明确问题去搜，拿到答案即止。禁止漫游式搜索——搜索时间挤占写作与自查时间，且过量信息会诱发"案例堆砌"通病。

## 时机一：审题阶段（Step 1，条件触发）

**触发条件**：题干含陌生概念、专有名词、引语出处，或疑似真题/模拟题原题。

**动作A：题干背景搜索**。若题干引用了学者观点（如2025"专转传"出自某学者论述）或特定概念（如"钝感力""附近性"），搜索「{概念} 含义 出处」。目的：确认概念的公认边界，防止工作定义偏离共识而被判审题偏差。落实：只取共识性定义融入首段的概念界定，不引用搜索到的长篇解读，更不照搬他人立意。

**动作B：真题解析搜索（强烈推荐）**。搜索「{题干关键词} 高考作文 审题 立意 解析」。若为真题，通常能找到官方专家点评或名师解析。目的：校准立意方向——确认自己的中心论点落在主流认知带内（"中规中矩"的保证），同时观察多数解析停在哪一层，自己的归因层与边界层要比它们深一层（"思想深刻"的保证）。落实：解析只用于校准审题结论，禁止照抄任何解析的提纲或范文表述；若自己的立意与所有解析方向相悖，重做Step 1。

## 时机二：素材获取（Step 2提纲完成后，按缺口搜索）

写完提纲后盘点引证缺口：哪个段落的例子与题意咬合不紧？evidence-bank中是否缺少贴合本题的时代性素材？只为缺口搜索，每个缺口一次。

**动作C：定向时代素材搜索**。搜索「{中心论点关键词} 事例/案例 {年份}」或直接检索确知存在的事件细节（如"《黑神话：悟空》 传统文化 传播"）。优先获取近两三年的鲜活案例——阅卷反馈显示"联系社会生活"是显性得分点，而LLM训练数据的时效滞后恰是短板，这是搜索的最大增值处。落实标准：每个搜来的案例入文前必须完成三步剪裁——(1)压缩到2-4句，只留与论点相关的侧面；(2)核对关键事实（人名、作品名、数字、时间）与来源一致；(3)写出≥2句例后阐释。无法通过三步剪裁的素材弃用。

**动作D：反例/争议面搜索**。为边界层（异化分析）搜索「{概念} 争议/批评/负面」，如"流量至上 批评""认可度 盲从 案例"。异化段有真实案例支撑（而非纯思辨推演）能显著增强说服力。同样执行三步剪裁。

## 时机三：引用验证（Step 3成文中，硬性要求）

**动作E：引文核验**。凡使用evidence-bank之外的名言、诗句、书名、观点归属，成文前必须搜索验证：「"{引文片段}" 出处」。验证标准：至少一个可靠来源（百科、出版物、权威媒体）确认原文与归属者一致。验证不通过的处理：改为不署名转述（"有学者指出……"），或删除。**禁止凭搜索结果中单一自媒体页面确认名言归属**——网络伪名言（尤指鲁迅、杨绛、莫言名下）泛滥，拿不准就转述。

**动作F：事实核验**。文中出现的具体数字、年份、作品与作者的对应关系（如"《时间简史》作者霍金""曹雪芹披阅十载"），若非十足把握，一并快速核验。张冠李戴是阅卷中AI被识破的标志性错误，一处即毁全文。

## 搜索结果落实的总纪律

第一，**搜索所得永远是原料不是成品**：任何搜到的句子不得直接进入作文，必须经过自己的语言重写并与观点句焊接（例后阐释）。直接挪用解析或范文语句既有查重风险，也必然产生风格断裂。

第二，**素材增量封顶**：搜索最多为全文新增2个案例。全文例子总量仍受结构规则约束（每段≤2例，全篇事例2-3个），搜到再好的素材也不突破——多例堆砌是通病6的直接诱因。

第三，**时效素材优先但不猎奇**：选择有公共认知度的近期事件（重大科技进展、现象级文化作品、广泛讨论的社会现象），避免小众争议事件——阅卷人没听说过的例子等于无效论证，且叙述成本高。

第四，**搜索失败不恋战**：某次搜索两轮内未获可用结果，立即放弃该缺口，回退到evidence-bank素材或纯思辨推进。一段扎实的归因分析胜过一个勉强的例子。

## 快速决策表

| 情形 | 是否搜索 | 动作 |
|------|----------|------|
| 题干概念全部熟悉、非真题 | 否 | 直接走离线流程 |
| 题干有陌生概念/引语 | 是 | 动作A |
| 疑似真题或模拟题 | 是 | 动作B校准立意 |
| 提纲中某段缺贴题案例 | 是 | 动作C/D，最多补2例 |
| 想用evidence-bank外的引文 | 必须 | 动作E，不通过则转述或删 |
| 文中含具体数字/作品归属 | 拿不准就搜 | 动作F |
