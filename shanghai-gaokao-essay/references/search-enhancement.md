# 搜索增强与证据核验（有搜索能力时必读）

核心原则：**搜索服务于论证，不服务于堆料；一切入文的专名、数字、引文必须能在证据账本里找到一行。** 无搜索能力时跳过本文件，只使用 `evidence-bank.md` 里标〔直引〕/〔转述〕的条目，并遵守其红线；离线流程自足可用。

为什么要强制：上海评分细则（公开转载的2018年版）要求论据真实，编造、明显错误或不能佐证观点的要酌情扣分；2026 年阅卷老师评 AI 作文时点名了"虚构素材"（一篇作文里的"天问一号年轻团队推翻轨道方案"查不到任何来源）；网络伪名言泛滥（见 evidence-bank 第5节）。本 skill 旧版的基线测试里也出现过"来源写的是具体数字，成文时泛化成'某些商品'"这类悄悄偏离来源的写法——账本就是为了让这种漂移被看见。

## 1. 证据账本（Evidence Ledger）

模板见 `assets/evidence-ledger.md`。**在 Step 2 提纲之后、Step 3 成文之前**把所有拟用的外部事实填进账本；搜索集中在这一步做完，成文中途不再打断。

状态只有四种：`verified`（来源确认，可用）｜`paraphrase-only`（概念属实但措辞不稳，只准转述不加引号）｜`weakened`（来源支持的范围比拟写的小，已把表述降到来源范围内）｜`dropped`（查不实，删除）。

**闸门（Step 4 必查）**：成稿里每个人名、作品名、事件、数字、引号内的话，都能映射到账本一行且状态不是 dropped。有代码执行时用 `python scripts/check_essay.py claims essay.md` 抽取待核验清单，逐条对账；账本外的陈述，要么补查，要么删除。evidence-bank 中的条目视为已有账本行（其来源见 `assets/evidence-audit.json`）。

## 2. 来源分级

| 级别 | 来源 | 用法 |
|---|---|---|
| T1 | 官方与原始：上海市教育考试院（shmeea.edu.cn）、新华网/人民网/央视、政府与权威机构、出版社与图书馆页面、诺贝尔奖官网、博物馆、期刊与百科全书（如 SEP）、原著全文库 | 可单独作为依据 |
| T2 | 维基百科/维基文库/维基语录、Project Gutenberg、主流媒体报道 | 需与一个 T1 或另一个独立 T2 互证 |
| T3 | 自媒体、公众号、知乎、问答、博客、百度百科 | **永远不能单独作为依据**，只作线索去找 T1/T2 |

2026-10-18 实测可访问的资源（`curl -A 'Mozilla/5.0'` 可抓取；`web_extract` 对不少站点会被拦，则改用 curl）：
- 上海市教育考试院 `shmeea.edu.cn`：每年作文题"专家点评"全文（用于审题校准）。
- 中文维基文库 `zh.wikisource.org`：古文、鲁迅著作全文；**页面内容可能是繁体或带异文**，核验时用 `?variant=zh-hans` 看简体，搜索古文引文用繁体关键词。
- 北京鲁迅博物馆资料查询在线检索系统 `http://www.luxunmuseum.com.cn/cx/`（可访问；另有 `cx.luxunmuseum.com.cn` 域名，实测连接失败，以前者为准）。鲁迅名下的话先在此核对，查不到的一律不署名鲁迅。
- 中国哲学书电子化计划 `ctext.org`：先秦两汉典籍原文；页面可用 curl 抓取，批量访问会触发安全检查。
- `chinese-poetry` 开源仓库（GitHub）：唐宋诗词 JSON，用于核对诗词原文与作者。

## 3. 按类型的核验门槛

| 类型 | 门槛 |
|---|---|
| 引文（加引号的话） | T1/T2 一手或权威全文中**逐字命中**，且作者、篇名一致；否则不加引号、不署名，改转述。外国文献的中文译本措辞不一，一律转述 |
| 转引 | 作者转引他人的话，要署原作者，或写"某某转引"（例：鲁迅转引圣·蒲孚） |
| 事件/案例 | ≥2 个独立来源（至少一个 T1/T2）且时间、主体一致；只写来源支持的范围，**不得泛化**（来源写"某商品销量百万、评价仅百余条"，不能写成"许多商品"） |
| 数字 | T1 来源；取整并写明口径与年份；找不到 T1 就不用数字 |
| 作品↔作者/年代 | 1 个 T1/T2（书目、出版社、全文库） |
| 人物生平细节 | 只写来源明确的部分；有争议的生卒年、销量等不写具体值（见 evidence-bank 曹雪芹、梵高条） |
| 学术概念与提出者 | SEP/学术来源确认概念、提出者和出处；"某定律/某效应"是否为原作者所用术语要区分（例：峰终定律 vs. Fredrickson 与卡尼曼） |

## 4. 搜索动作（全部在成文前集中完成）

预算：**有账本时共 6–10 次搜索**，每条陈述最多 2 次查询；两轮内无可用结果就放弃该缺口，回退到 evidence-bank 或纯思辨推进。禁止漫游式搜索——素材过多会诱发"案例堆砌"。

**A 题干背景**（条件触发：题干有陌生概念、学者引语、专名）：搜「{概念} 含义 出处」，只取共识性定义融入首段概念界定，不引长篇解读，不照搬他人立意。

**B 真题校准**（疑似真题或模拟题；强烈推荐）：先查 `assets/past-prompts.md`；若是真题，抓取上海市教育考试院该年"专家点评"，确认立意落在官方列出的立意空间内（"中规中矩"的保证），并观察其停在哪一层，自己的归因层与边界层要比它深一层。解析只用于校准，禁止照抄任何解析的提纲或表述；自己的立意与所有解析相悖就重做 Step 1。

**C 时代素材**（提纲有素材缺口时）：搜「{论点关键词} 事例 {年份}」，优先近两三年、有公共认知度的事件。每个搜来的案例入文前必须三步剪裁：(1)压缩到2–4句，只留与论点相关的侧面；(2)关键事实（人名、作品名、数字、时间）与来源逐项核对并写进账本；(3)写出≥2句例后阐释。过不了三步就弃用。

**D 反例/争议面**（为边界层）：搜「{概念} 争议 批评 案例」，同样三步剪裁。

**E 引文核验**（凡 evidence-bank 之外的名言、诗句、书名、观点归属）：按第3节门槛。用「"{引文片段}" 出处」检索，**不得凭单一自媒体页面确认归属**；鲁迅名下的话查鲁迅博物馆检索系统；古文查维基文库/ctext。

**F 事实核验**（具体数字、年份、作品与作者对应）：拿不准就搜；张冠李戴一处即毁全文。

## 5. 落实纪律

1. **搜索所得是原料不是成品**：任何搜到的句子不得直接进入作文，必须用自己的话重写并与观点句焊接（例后阐释）。
2. **增量封顶**：搜索最多为全文新增2个案例；全文例子总量仍受结构规则约束（每段≤2例，全篇事例2–3个）。
3. **不泛化、不加码**：成文时的措辞强度不得高于来源（"可能"不能写成"必然"；"部分"不能写成"普遍"）。
4. **时效素材优先但不猎奇**：选有公共认知度的近期事件；阅卷人没听说过的例子等于无效论证。账本里记下取材日期。
5. **搜索失败不恋战**：一段扎实的归因分析胜过一个勉强的例子。

## 6. 可选：独立复核

重要稿件（如要发表或作为范文）可用 `delegate_task` 派一个没写过这篇文章的子 agent，只给它账本和成稿，让它逐条重新检索并回报与账本不一致之处。写作者与核验者分离，可降低自证偏差。子 agent 的自述不直接采信：抽查几条回看来源。

## 7. 快速决策表

| 情形 | 动作 |
|---|---|
| 题干概念全部熟悉、非真题、提纲素材全在 evidence-bank | 可不搜索，账本只记 evidence-bank 条目 |
| 题干有陌生概念/引语 | A |
| 疑似真题/模拟题 | B（先查 past-prompts） |
| 提纲某段缺贴题案例 | C/D，最多补2例 |
| 想用 evidence-bank 外的引文 | 必须 E，不通过则转述或删 |
| 文中含具体数字/作品归属 | F |
