# 全流程/精简示范：三道真题覆盖A/B/C三种题型

本文件以真题演示Step 1-3的工作过程，作为质量标尺。写作新题时对照本示范的思维密度与语言水位。第一份（A型）为完整全流程示范；第二、三份（B型、C型）为精简示范，聚焦审题结论、提纲与最关键的1-2个段落，篇幅更短但思维动作同样完整，不可因为"精简"而降低思维密度的参照标准。

## A型全流程示范：2025年上海卷"专转传"

### 真题

> 有学者用"专""转""传"概括当下三类文章："专"指专业文章；"转"指被转发的通俗文章；"传"指获得广泛传播的佳作，甚至是传世文章。他提出，专业文章可以变成被转发的通俗文章，而面对大量"转"文，读者又不免期待可传世的文章。由"专"到"传"，必定要经过"转"吗？请联系社会生活，写一篇文章，谈谈你的认识与思考。

### Step 1 审题结论

```
题型：A 设问质疑型（"必定要…吗"），内嵌三概念关系
核心概念工作定义：
  专＝面向少数内行的专业写作，价值在深度与准确
  转＝借通俗化获得即时流量的传播形态，价值在可及性，度量单位是热度
  传＝经受时间检验的广泛而持久的流传，度量单位不是热度而是生命力
隐含前提（靶子）："转"是"专"通向"传"的必经中转站——把传播的"广"与流传的"久"混为一谈
最终问句：由"专"到"传"，必定要经过"转"吗？
中心论点：由专到传未必要经过转；转能扩大抵达面却不能授予生命力，真正决定"传"的，是作品对人类恒常问题的回应力。
归因层：为何人们相信"必经转"——注意力经济时代，流量成了唯一可见的价值度量；酒香也怕巷子深的传播焦虑。
边界层：当"转"从通道变成目的，专业写作向流量逻辑让渡深度，"十万+"的速朽反而堵死了通往"传"的路。
```

### Step 2 提纲

```
标题：《"转"非必经，回应为桥》
第1段 引论（120字）：从"十万+"刷屏与速朽的现象切入；界定专/转/传的价值坐标差异（热度 vs 生命力）；亮观点：由专到传，未必经转。
第2段 让步（180字）：诚然，转有其功——归因：注意力经济中，再深刻的文字若无人抵达便无从流传；例：《时间简史》以通俗化让宇宙学走入千家万户。
第3段 深掘一（200字）：但"转"的逻辑与"传"的逻辑不同质：转追逐即时共鸣，传依赖恒常回应。例：《赤壁赋》无任何"转"的爆红，凭对生命困境的回应流传千年；陈景润的论文从未通俗化，仍成学术之"传"。
第4段 深掘二·异化（200字）：更值得警惕的是，当转成为必经之路的信条，专业写作被流量逻辑反噬——标题党、简化、迎合；热搜的速朽恰证明"广的抵达"不等于"久的留存"。
第5段 升维（180字）：重新定义——传的通行证不是流量而是回应力；转是"渡口"而非"关卡"，真正的桥是作品与人心恒常问题的相遇。
第6段 结语（100字）：写作者当以回应时代与人心为志，善用转而不困于转；由专到传的路，最终由价值铺就。
```

### Step 3 关键段落成文示范

#### 首段（水位标尺）

> 今天，一篇文章的命运常被折算成转发量："十万+"意味着成功，无人问津似乎就等于失败。于是有了这样的想象：专业文章要想流传，必得先变成人人转发的通俗爆款。可是，"转"度量的是一时的热度，"传"依凭的却是长久的生命力——二者并不同质。由专到传，未必要经过转；真正决定一篇文章能否流传的，是它对人心恒常问题的回应力。

#### 让步段起笔

> 诚然，"转"自有其功。在注意力稀缺的时代，再深刻的思想若无人抵达，便只能在故纸堆中沉睡。霍金的《时间简史》正是把艰深的宇宙学翻译成大众可感的语言，才让黑洞与时间走进了千家万户。承认这一点，是承认传播本身的正当价值：酒香也怕巷子深，通俗化是专业成果对公众的一种善意。

#### 异化段核心句示范

> 更值得警惕的是，当"必经转"从描述变成信条，流量逻辑便开始反噬写作本身：为了可转发，标题必须惊悚，论证必须简化，立场必须迎合。"转"本是渡口，却被当成了关卡；专业写作若以让渡深度换取热度，便是拆掉了自己通往"传"的桥。热搜的速朽早已给出证词——昨日刷屏之文，今日无人记起，"广的抵达"从来不等于"久的留存"。

#### 结语示范

> 归根结底，"转"是渡口而非关卡，可借而不可恃。写作者真正要做的，是让文字回应人心中恒常的问题——如此，纵使不经爆款的喧嚣，文章自会在时间中找到它的读者。由专到传的路，最终由价值铺就，而不由流量丈量。

### A型质量标尺说明

对照本示范自检四点：第一，观点句是否像首段末句那样直接、限定、含题干关键词；第二，让步段是否真的替对方说话（而非敷衍一句就转折）；第三，异化段是否有"从手段变目的"的机制分析（而非简单罗列坏现象）；第四，结语是否回扣标题题眼（"桥""渡口"）且不引入新内容。新题成文的思想密度与语言水位不得低于本示范。

## B型精简示范：2021年上海卷"时间的沉淀"

### 真题

> 有人说，经过时间的沉淀，事物的价值才能被人们认识；也有人认为不尽如此。你怎么看？请写一篇文章，谈谈你的思考。

### Step 1 审题结论

```
题型：B 观点评价型（"有人说A，也有人认为不尽如此"）
A方核心主张：事物价值的显现依赖时间的沉淀（工作定义：时间＝去除干扰、允许检验的过程，而非单纯的等待）
B方隐含主张：并非所有价值都需要／能靠时间显现——有些价值当下即可判定，有些价值即便经过时间也未必被认识，甚至被时间掩埋
双方共享的错误预设：把"时间"简单等同于"价值显现的充分条件"，忽略了"什么样的时间"以及"谁在场检验"
中心论点：时间本身不创造价值判断，它只提供检验价值的场域；真正决定价值能否被认识的，是检验主体是否具备穿透喧嚣的眼光和标准的稳定性。
```

### Step 2 提纲

```
标题：《检验场，而非保险箱》
第1段 引论：从"时间会证明一切"这类流行说法切入；界定"时间的沉淀"＝检验的场域而非自动生效的机制；亮观点：时间不创造价值，只提供检验场。
第2段 析A方合理性：短期喧嚣常掩盖真实价值，需要时间去除干扰（例：部分经典作品初出时反应平淡，多年后被重新发现）；归因：当下判断易受流量、立场、群体情绪干扰。
第3段 析A方边界：但并非所有价值都需等待——有些危害或价值当下即可用理性判断认清，"必须等时间"有时是逃避即时判断责任的借口。
第4段 析B方深掘：反过来，"时间会自动澄清一切"同样是幻觉——大量真正有价值的事物因无人持续检验、记录、传承而被时间悄悄掩埋，而非"沉淀"出来；时间是中性的场域，不是正义的必然结果。
第5段 升维：真正决定价值能否被认识的，不是时间的长度，而是检验主体是否具备穿透喧嚣的稳定标准与持续关注；时间只给了检验的机会，未必兑现检验的结果。
第6段 结语：与其被动等待时间沉淀，不如主动锻造判断的眼光与保存价值的意愿；回扣"沉淀"二字——真正的沉淀是主动的打磨与守护，而非静置的等待。
```

### 关键段落示范

首段：

> "时间会证明一切"，这句话常被用来安慰一时不被理解的坚持，也常被用来搪塞对当下判断的懒惰。经过时间的沉淀，事物的价值才能被认识——这话对了一半：时间确实提供了一个去除喧嚣、允许反复检验的场域；但时间本身并不创造价值判断，它只是一片检验场，而非自动生效的保险箱。真正决定价值能否被认识的，是站在时间里的人，是否具备穿透喧嚣的眼光与判断标准的稳定性。

B方深掘段：

> 但反过来说，"时间会自动澄清一切"同样是一种幻觉。历史从不缺少这样的例子：某些真正有价值的思想或作品，恰恰因为无人持续记录、传承与追问，被时间悄悄掩埋，而不是"沉淀"了出来。时间对一切事物一视同仁地流逝，却不会一视同仁地为它们保留位置——保留位置的，是持续在场的关注与判断，而不是时间本身。

### B型质量标尺说明

B型题的最大风险是"只评一方、另一方沦为陪衬"。本示范第2、3段处理A方（合理性+边界各成一小循环），第4段单独处理B方的边界（而非把B方当成理所当然的靶子），第5段才给出超越两方共享预设的整合立场——这个顺序不能打乱，也不能压缩成"各打五十大板"的空泛表态。

## C型精简示范：2024年上海卷"认可度"

### 真题

> 生活中，人们常用认可度判别事物，区分高下。请写一篇文章，谈谈你对"认可度"的认识和思考。

### Step 1 审题结论

```
题型：C 概念阐释型（"谈谈你对X的认识和思考"）
核心概念工作定义：认可度＝他人（或群体）对某事物给出的公开评价总量与倾向，常以量化或排名形式呈现（点赞数、评分、销量、排行榜）
认可度的价值：为个体在信息过载中提供了快速判断的捷径，降低了独立判断的认知成本
认可度的局限/异化：当"认可度"从参考指标变成唯一标准，判别价值的权力从"事物本身的质地"让渡给"多数人的即时反应"，催生迎合与同质化
中心论点：认可度是一种有用但有限的参照系统，它衡量的是"被多少人接受"，而非"本身有多好"；真正健全的判别力，是把认可度当作起点而非终点的独立判断力。
```

### Step 2 提纲

```
标题：《参照系，不是判决书》
第1段 引论：从各类评分、排行榜、点赞数主导选择的现象切入；界定认可度＝群体反应的量化呈现；亮观点：认可度是参照系，不是判决书。
第2段 让步：认可度确有其功——归因：面对海量选择，个体不可能对每件事物都亲自深入判断，认可度是降低认知成本的有效捷径（例：陌生领域借助大众评分做初步筛选）。
第3段 深掘一：但认可度衡量的是"被接受的广度"，不是"本身的质地"——例：许多历史上开创性的思想或作品在诞生时认可度极低甚至被否定，价值与即时认可度并不同步。
第4段 深掘二·异化：更值得警惕的是，当认可度被当作唯一标尺，创造者与判断者会不自觉地向"更容易被认可"让渡——迎合、同质化、追逐热点，判别价值的主动权从"事物本身"让渡给了"多数人的即时反应"。
第5段 升维：真正健全的判别力，是把认可度当作众多参考之一而非终点——先了解认可度提示的方向，再回到事物本身去独立核验，形成自己的判断。
第6段 结语：认可度可以是起点，不该是终点；愿我们既善用它降低选择成本，也保留住不被多数意见代劳的独立判断权。
```

### 关键段落示范

首段：

> 一部电影该不该看，常常先看评分；一件商品值不值得买，先看销量与好评率。认可度——人们对事物的公开评价总量与倾向——已经成了这个时代最常用的判别尺。但认可度衡量的是"被多少人接受"，而不是"事物本身有多好"；它更适合做参照系，而非判决书。

异化段：

> 更值得警惕的是，当认可度被当作唯一的评判标准，创造者与判断者会不自觉地向"更容易被认可"倾斜：内容趋向标题党式的刺激，产品趋向讨好大多数的平庸，判别价值的主动权，就这样从"事物本身的质地"悄悄让渡给了"多数人此刻的即时反应"。

### C型质量标尺说明

C型题最容易写成"认可度的利与弊"两点式罗列。本示范用"认可度衡量的是广度而非质地"这一核心区分贯穿深掘段与异化段，避免泛泛而谈；升维段给出"参照系/起点，非终点"的明确姿态，而非"认可度既重要又要警惕"的折中滑过。
