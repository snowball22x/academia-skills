# 全流程示范：真题案例库（覆盖A/B/C/D/E题型）

本文件以真题演示Step 1-2（审题结论与提纲）的完整工作过程，作为**思维密度**的标尺。写作新题时对照本示范的审题深度与段落功能分配。**本版不再附成文段落示范**（唯一例外是示范一的首段，仅作水位参照）：旧版附的全文示范被逐字复刻，造成同一 skill 写出的作文口头禅趋同（见 de-template.md 第0节）。目前覆盖A型（设问质疑型）、B型（观点评价型）、C型（概念阐释型）、D型（关系思辨型）、E型（寓言设喻型）各一例。

## 示范一：A型（设问质疑型）——2025年上海卷"专转传"

### 真题

> 有学者用"专""转""传"概括当下三类文章："专"指专业文章；"转"指被转发的通俗文章；"传"指获得广泛传播的佳作，甚至是传世文章。他提出，专业文章可以变成被转发的通俗文章，而面对大量"转"文，读者又不免期待可传世的文章。由"专"到"传"，必定要经过"转"吗？请联系社会生活，写一篇文章，谈谈你的认识与思考。

### Step 1 审题结论

```
题型：A 设问质疑型（"必定要…吗"），内嵌三概念关系
核心概念工作定义：
  专＝面向少数内行的专业写作，价值在深度与准确
  转＝借通俗化获得即时流量的传播形态，价值在可及性，度量单位是热度
  传＝经受时间检验的广泛而持久的流传，度量单位不是热度而是生命力
隐含前提（靶子）："转"是"专"通向"传"的必经中转站——把传播的"广"与流传的"久"混为一谈
最终问句：由"专"到"传"，必定要经过"转"吗？
中心论点：由专到传未必要经过转；转能扩大抵达面却不能授予生命力，真正决定"传"的，是作品对人类恒常问题的回应力。
归因层：为何人们相信"必经转"——注意力经济时代，流量成了唯一可见的价值度量；酒香也怕巷子深的传播焦虑。
边界层：当"转"从通道变成目的，专业写作向流量逻辑让渡深度，"十万+"的速朽反而堵死了通往"传"的路。
```

### Step 2 提纲

```
标题：《"转"非必经，回应为桥》
第1段 引论（120字）：从"十万+"刷屏与速朽的现象切入；界定专/转/传的价值坐标差异（热度 vs 生命力）；亮观点：由专到传，未必经转。
第2段 让步（180字）：转有其功——归因：注意力经济中，再深刻的文字若无人抵达便无从流传；例：《时间简史》以通俗化让宇宙学走入千家万户。
第3段 深掘一（200字）：但"转"的逻辑与"传"的逻辑不同质：转追逐即时共鸣，传依赖恒常回应。例：《赤壁赋》无任何"转"的爆红，凭对生命困境的回应流传千年；陈景润的论文从未通俗化，仍成学术之"传"。
第4段 深掘二·异化（200字）：当转成为必经之路的信条，专业写作被流量逻辑反噬——标题党、简化、迎合；热搜的速朽恰证明"广的抵达"不等于"久的留存"。
第5段 升维（180字）：重新定义——传的通行证不是流量而是回应力；转是"渡口"而非"关卡"，真正的桥是作品与人心恒常问题的相遇。
第6段 结语（100字）：写作者当以回应时代与人心为志，善用转而不困于转；由专到传的路，最终由价值铺就。
```

### 水位参照（全文仅此一段，禁止复用其句式）

> 今天，一篇文章的命运常被折算成转发量："十万+"意味着成功，无人问津似乎就等于失败。于是有了这样的想象：专业文章要想流传，必得先变成人人转发的通俗爆款。可是，"转"度量的是一时的热度，"传"依凭的却是长久的生命力——二者并不同质。由专到传，未必要经过转；真正决定一篇文章能否流传的，是它对人心恒常问题的回应力。

### 质量标尺说明

对照本示范自检四点：第一，观点句是否像首段末句那样直接、限定、含题干关键词；第二，让步段是否真的替对方说话（而非敷衍一句就转折）；第三，异化段是否有"从手段变目的"的机制分析（而非简单罗列坏现象）；第四，结语是否回扣标题题眼（"桥""渡口"）且不引入新内容。新题成文的思想密度与语言水位不得低于本示范。

## 示范二：B型（观点评价型）——2021年上海卷"时间的沉淀"（精简示范）

### 真题

> 有人说，经过时间的沉淀，事物的价值才能被人们认识；也有人认为不尽如此。你怎么看？请写一篇文章，谈谈你的思考。

### 审题结论

```
题型：B 观点评价型（"有人说A，也有人认为不尽如此"）
核心概念工作定义：
  时间的沉淀＝价值显现所需要的检验过程，本质是排除即时因素（流行、权力、偏见）干扰后的甄别机制，而非时间本身产生价值
A方合理性：许多价值确需时间剥离喧嚣才能显现（经典作品重估、历史人物评价）
A方边界：并非所有价值都需要等待——有些价值当下即可通过严格的甄别方式被认识（科学真理经实验即时验证；显而易见的善举/伤害无需等待）
中心论点：时间沉淀是价值显现的常见路径之一，而非必要条件；真正决定价值能否被认识的，是是否存在足够公允、足够严格的甄别机制——时间只是其中最常见、最省力的一种。
```

### 提纲

```
标题：《甄别之力，不止于时间》
第1段 引论（130字）：从"经典重估""过气网红"等现象切入；界定"时间的沉淀"＝排除即时干扰的甄别机制；亮观点：时间是常见路径，非必要条件。
第2段 析A方合理性（180字）：许多价值需要时间剥离流行、权力、偏见的遮蔽才能显现——例：梵高生前寂寥身后画价千万；归因：即时评价常受制于短期利益和集体偏见，时间能稀释这些干扰。
第3段 析A方边界（200字）：但时间沉淀并非充分条件也非必要条件——例：某些价值当下即可用严格甄别验证（科学定理的实验证伪；见义勇为的当下即可判断）；时间本身不产生价值，只是提供了一个（并非唯一的）过滤噪声的场域。
第4段 深掘·异化（200字）：需警惕"唯时间论"的懒惰——把"暂未被认可"简单等同于"终将被认可"，成为平庸之作自我安慰的借口；不是所有沉底之物都是遗珠，多数只是被时间正确地遗忘了。
第5段 整合升维（170字）：真正决定价值显现的，不是时间的长度，而是甄别机制的公允度——时间只是当下缺乏更优甄别手段时的替代方案；随认知工具进步，一些价值的显现可以不必等待时间。
第6段 结语（100字）：与其消极等待时间证明自己，不如主动追问：当下是否已存在能公允甄别价值的方式；这是比"相信时间"更主动的姿态。
```

## 示范三：C型（概念阐释型）——2024年上海卷"认可度"（精简示范）

### 真题

> 生活中，人们常用认可度判别事物，区分高下。请写一篇文章，谈谈你对"认可度"的认识和思考。

### 审题结论

```
题型：C 概念阐释型（"谈谈你对X的认识和思考"）
核心概念工作定义：
  认可度＝群体对某事物的接受与认同程度的量化表达，本质是"他人目光的加总"，用作判别事物高下的一种社会性代理指标
X的价值（人们为何依赖它）：认可度提供了低成本的判别捷径——个体认知有限，借助群体共识可以快速定位事物的相对位置，节省独立判断的成本
X的局限与异化：认可度会被流量、算法、从众心理裹挟，导致"高认可度≠高价值"（哗众取宠者认可度虚高，深刻但小众者认可度虚低）；当认可度从"参考"异化为"标准"，判别标准就从事物本身转移到了他人的目光
中心论点：认可度是判别事物的一种便捷参考，而非价值本身；真正的高下判断，最终仍须回到事物本身的内在标准，认可度只应是起点，不应是终点。
```

### 提纲

```
标题：《认可度是起点，不是终点》
第1段 引论（130字）：从"点赞数""好评率"等现象切入；界定认可度＝他人目光的加总，一种判别捷径；亮观点：认可度是参考起点，非价值终点。
第2段 认可度的价值（180字）：认可度确有其功——个体认知有限，借助群体共识能快速筛选、降低试错成本；例：口碑良好的书籍/餐馆帮助人们节省甄选时间；归因：这是一种集体智慧的低成本利用方式。
第3段 认可度的局限（200字）：但认可度可被操纵、被裹挟——流量算法制造虚假热度，从众心理制造沉默的螺旋；例：短视频靠猎奇获得高认可度，却与内容价值无关；深刻但曲高和寡的作品长期认可度偏低，却不减其价值。
第4段 深掘·异化（200字）：当认可度从"参考"异化为唯一"标准"，人们开始用他人目光替代自己的判断——为博认可而表演、为迎合而妥协，事物本身的内在标准被悬置。
第5段 整合升维（170字）：真正的认可度应是"经得起时间和内在标准检验的共识"，而非当下声量的加总——重新界定：认可度的意义在于提示我们去关注、而非替我们下判断。
第6段 结语（100字）：面对纷杂的认可度数字，我们应保留独立审视的能力，让认可度成为发现事物的起点，而非评判价值的终点。
```

## 示范四：D型（关系思辨型）——2026年上海卷"科技与想象"

### 真题

> 每个人都有对世界的想象。科技改造世界时，也改造着我们的想象。对此你有怎样的认识和思考？请写一篇文章。要求：（1）自拟题目；（2）不少于800字。

### Step 1 审题结论

```
题型：D 关系思辨型（科技与想象的双向作用关系），非单一概念阐释、非绝对化设问
核心概念工作定义：
  想象＝人超越当下感知、主动建构世界可能性的思维方式，是人确证自身能动性的维度
  科技改造想象＝科技不仅是想象的实现工具，反过来也塑造、规训、重新划定想象的边界和形态
常识粗糙之处：把"科技"简化为中性工具，把"想象"简化为不受影响的纯主观活动——二者被割裂看待，忽视了材料中"也"字点明的双向性
真实关系模型（互构）：科技把"不可想象"变为可感可用的现实，反过来扩展了想象的素材库和参照系（正向互构）；但科技的呈现方式、算法逻辑也预先框定了"可以想象什么"，形成隐性的想象边界（负向互构）
隐含前提（靶子）：材料的重心不在"科技"而在"想象"，题干动词是"改造"——考生须论证想象被改造后是"更丰盈"还是"被窄化"，不能写成科技利弊泛论而丢掉"想象"这一核心对象
中心论点：科技与想象并非单向的"工具服务于目的"，而是互相塑造的动态关系——科技拓宽了想象的边界，也可能悄然收窄想象的自由；想象要不被技术逻辑吞没，关键在人能否保有"对想象本身的想象"，即对技术前提的反思能力
归因层要点：为何人容易把科技对想象的改造等同于纯粹的"赋能"——技术呈现的可能性直观、即时、可验证，比未经技术中介的想象更容易被当成"更真实"的想象，人因此逐渐把技术提供的选项当成想象力的全部边界
边界层要点：当想象完全依赖技术生成的素材（如算法推荐的内容、AI生成的图像），想象便从"主动建构"异化为"被动接受技术预设的选项"——想象的自由被技术逻辑不知不觉地代管
```

### Step 2 提纲

```
标题：《科技拓界，想象莫困于界》
第1段 引论（130字）：从AI绘图、虚拟现实等"科技带来新奇想象素材"的现象切入；界定想象＝主动建构世界可能性的思维方式；亮观点：科技拓宽想象边界，也可能收窄想象自由，关键在人能否保有对技术前提的反思。
第2段 正论·科技拓宽想象（180字）：承认科技确实扩展了想象的素材库和参照系——归因：科技把"不可想象"变为可感可验证的现实，为想象提供了此前不存在的坐标；例：望远镜与宇宙探测拓宽了人类对"世界"的想象边界，使"外星生命""多重宇宙"从纯臆想变为可严肃讨论的想象对象。
第3段 深掘一·边界显现（200字）：但科技对想象的"改造"并非单向赋能——算法推荐、生成式AI在提供素材的同时，也预先设定了"可想象的范围"；例：依赖AI生成图像的创作者，逐渐习惯于在算法给出的风格与组合中"选择"而非真正"构想"，想象力悄然收窄为对既有选项的挑选。
第4段 深掘二·异化（200字）：当人把技术呈现的可能性直接当成想象力的全部边界，"对世界的想象"便从主动建构异化为被动接受技术的预设——技术从"想象的工具"变成了"想象的框架"，人反而在技术打开的广阔天地里丧失了自主构想的能力。
第5段 升维（180字）：真正健康的科技与想象的关系，不是谁改造谁的单向支配，而是互相激发又互相制衡的动态平衡——人既借科技拓展想象的疆域，又须保有"对想象本身的想象"，即不断反思技术呈现给自己的选项是否已是想象的全部可能。
第6段 结语（100字）：面对科技对想象的持续改造，我们不必因此忧惧想象力的消亡，也不可放任想象被技术悄然代管；愿以清醒的反思力为锚，让科技成为想象展翅的风，而非圈住想象的笼。
```

## 示范五：E型（寓言设喻型）——2026年上海青浦区二模"丑小鸭与共情"

### 真题

> 丑小鸭跟天鹅之间的差异，其实和两只天鹅之间的差异一样大。这揭示了人对世界的观察都带着主观视角，这是否意味着人与人之间无法产生真正的共情与感同身受？请写一篇文章，谈谈你对这个问题的认识和思考。

### Step 1 审题结论

```
题型：E 寓言设喻型（内嵌A型设问）
比喻解码：
  丑小鸭与天鹅的差异→个体与个体之间"可感知"的属性差异
  两只天鹅之间的差异→任何个体之间（哪怕看似同类）都存在同样显著的差异
  寓言论证的指向→既然人人都生活在差异之中，观察必然带着各自的视角
  对应边界：材料说的是"感知有主观性"，并未直接证明"共情不可能"——从"视角有主观性"到"共情不可能"之间存在逻辑跳跃，这正是可以攻击的隐含前提
最终问句：这是否意味着人与人之间无法产生真正的共情与感同身受？
限定词追问："真正的共情"是什么？——若定义为"完全复刻对方感受"，则确实不可能；若定义为"持续靠近的理解"，则可能。本题是典型的定义之争。
中心论点：视角的主观性确实使"完全的感同身受"不可能，但这恰恰不是共情的失败——真正的共情从来不是完全抵达，而是带着自身视角的局限，持续地、谦卑地靠近对方；承认有限，正是共情得以真诚的前提。
归因层要点：向内——认知吝啬与范畴化滤镜让我们用既有经验"翻译"他人；向外——算法推荐与圈层化社交让"以己度人"获得源源不断的同温层佐证，共情的练习场正在收缩。
边界层要点（对称双防）：防"共情万能"绝对化——自以为完全懂得对方的"共情"，实为居高临下的凝视与傲慢（"何不食肉糜"）；防"共情不可能论"的滥用——以差异为借口放弃理解的意愿，滑向冷漠的合理化。
```

### Step 2 提纲

```
标题：《有限的理解，无限的靠近》
第1段 引论（130字）：从寓言切入并完成解码；点出隐含前提；亮观点：完全抵达不可能，持续靠近即真共情。
第2段 让步（180字）：承认差异与视角的客观存在——我们只能用自己的经验翻译他人；例：庄子"子非鱼"，晋惠帝"何不食肉糜"正是经验边界外的误读；归因：范畴化滤镜是认知经济的代价。
第3段 深掘一（200字）：驳"无法共情"的推论——从"不完全"推不出"不可能"；重新定义：共情的本质是意愿与靠近，而非感知的完全重合；例：加达默尔"视域融合"——理解是两个视域的对话融合，差异正是理解得以发生的前提。
第4段 深掘二·异化（200字）：两种极端——以"我懂你"自居的傲慢共情（实为凝视，例：居高临下的怜悯）；与以"永不同"为借口放弃理解的冷漠。对称双防后给出转化条件：承认有限、保持追问。
第5段 升维（180字）：真正的共情是"戴着眼镜依然看见彼此"——视角如镜片，不可摘除，但可以校准；共通的人性底色（对痛的畏惧、对善的渴望）使靠近成为可能。
第6段 结语（100字）：与其追问能否完全感同身受，不如追问是否保有靠近的意愿；承认差异而不放弃理解，是现代人最珍贵的共情姿态。
```
