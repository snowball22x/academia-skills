# 上海高考高分作文写作 (Shanghai Gaokao Essay, 62+/70)

写作目标定位：**"中规中矩 + 思想深刻"的一类下/二类上作文（62-66分）**。阅卷共识是两类作文能上一类卷——中规中矩思想深刻的，与众不同的创新作文。本skill只走第一条路，因为它稳定可复制。评分隐性权重：**立意 > 结构 > 语言**。

## 执行流程（严格按顺序，不可跳步）

**分支判断（先做这一步）**：用户给的是一个全新题目要求写一篇文章，还是已经有一篇草稿要求修改/升格/诊断问题？

- 全新题目 → 走下方 Step 0-4 完整流程，从审题到成文。
- 已有草稿（哪怕只是笼统地问"能不能再提提分"）→ 转读 references/revision-and-upgrade.md，按其诊断与分优先级升格流程处理；该文件仍会用到本文件的九大通病表和下方《交稿前分档自评表》作为判断依据，但不重新从头写一篇新文章，也不应在用户未要求时输出整篇替换稿。

```
Step 0 能力判断  → 若具备网络搜索能力，读 references/search-enhancement.md，按其时机表在后续各步嵌入搜索动作
Step 1 审题拆解  → 读 references/prompt-analysis.md，完成审题清单（陌生概念/真题：先搜索校准）
Step 2 立意与提纲 → 读 references/structure-and-outline.md，产出提纲（按素材缺口定向搜索，最多补2例）
Step 3 成文     → 读 references/language-and-style.md + references/evidence-bank.md，写全文（库外引用必须搜索核验）
Step 4 自查修改  → 用本文件末尾的《交稿前自查清单》逐项核对，再用《交稿前分档自评表》打分判断是否达标，修改后交付
```

每一步的输出（审题结论、提纲）必须先显式写出来再进入下一步，禁止直接一步成文。这是防止"审题浅、平均用力、观点不集中"这一AI最大失分点的核心机制。无搜索能力时跳过Step 0及所有搜索动作，离线流程自足可用。

## 必须规避的九大AI写作通病（阅卷名师实测反馈）

以下问题是无提示词的LLM在真实阅卷中被扣到50分档的直接原因，写作全程对照规避：

| # | 通病 | 对策（硬性规则） |
|---|------|------|
| 1 | 审题浅、答非所问 | 文章必须直接回应题干的**原始问法**（"必定要…吗""是否""你怎么看"），观点句中复现题干关键词 |
| 2 | 平均用力、观点分散 | 全文只论证**一个中心论点**；分论点必须是中心论点的展开而非并列话题 |
| 3 | 标题烂俗或空泛 | 禁用"破茧成蝶""扬帆起航"类意象；标题必须内含观点或核心概念关系，且题眼在正文中兑现 |
| 4 | 小标题式/论文腔结构 | 禁用小标题、序号分节；用过渡句衔接；避免"首先/其次/再次"式机械推进 |
| 5 | 中间大两头小、无结尾 | 首段≤150字快速入题亮观点；必须有独立结尾段，回扣题干+升华 |
| 6 | 案例堆砌、例证裸奔 | 每段最多1-2个例子，**例后必须有≥2句阐释**将例子绑定回论点；排例（三个以上连用）全文至多一处 |
| 7 | 引用幻觉、张冠李戴 | 只使用 references/evidence-bank.md 中已验证的引证；不确定出处的名言一律改为转述或删除 |
| 8 | 只正面阐释、缺深掘 | 必须包含"为什么"层（归因）和"边界"层（该观点被推向极端后的异化），单向度赞美/批判直接掉到二类中 |
| 9 | 衔接词滥用、机械转折 | "然而""但是"每篇≤3次；改用让步式过渡（"诚然……但这并不意味着……"）和设问式过渡 |

## 核心写作范式（速览）

上海卷全部为思辨性材料作文，四种题型（识别方法见 references/prompt-analysis.md）：

| 题型 | 特征 | 例 |
|------|------|-----|
| A 设问质疑型 | "仅仅/必定/是否…吗？" | 2023好奇心、2025专转传 |
| B 观点评价型 | "有人说…，也有人认为不尽如此" | 2021时间的沉淀 |
| C 概念阐释型 | "谈谈你对X的认识和思考" | 2024认可度 |
| D 关系思辨型 | A与B的关系/张力 | 2026科技与想象 |

所有题型共用一副**思辨五段骨架**（详见 references/structure-and-outline.md）：

1. **引论**：现象切入 → 概念界定 → 亮明中心论点（直接回应题干问法）
2. **正论/让步**：承认题干观点（或某一方）的合理性，说明它回应了什么真实需求
3. **驳论/深掘**：揭示其局限、隐含前提的问题、被极端化后的异化
4. **整合/升维**：重新界定概念，提出"真正的/成熟的X"，建立动态统一
5. **结语**：方法论收束 + 回扣题干关键词 + 联系时代与青年（落在具体认知姿态，不喊口号）

三个不可妥协的思维动作：**概念界定**（用"不是A，而是B"的排除式定义）、**让步论证**（先承认对方合理性再指出边界）、**主体性落点**（结尾回到人的主动选择权）。

## 硬性格式要求

全文900-1000字（安全区间，题目要求"不少于800字"）；自拟标题；纯议论文，不写记叙文、书信体、小标题体；简体中文；不分点罗列，全部以连贯段落行文；段落数6-8段。

## 交稿前自查清单（Step 4，逐项核对）

1. 观点句是否在第一段末出现，且直接回答了题干的原始问法？
2. 全文是否只有一个中心论点，每个分论点都服务于它？
3. 是否完成了概念界定（且用了排除式定义）？
4. 是否有让步段（承认对方合理性）？是否有归因层和边界/异化层？
5. 每个例子后是否有≥2句阐释？是否存在三例连排超过一处？
6. 所有引文是否都来自evidence-bank、经搜索核验、或确凿无疑？删除任何存疑引用；具体数字与作品归属是否已核验？
7. 标题是否含观点/概念，题眼是否在正文至少出现两次？
8. 结尾段是否回扣题干关键词并落在"人"的主体性上？
9. "然而/但是"是否≤3次？有无小标题、序号、分点？
10. 字数是否在900-1000字？（逐段估算，不足则加厚阐释而非加例子）

自查发现问题必须修改后再交付。若时间允许，模拟阅卷人视角通读一遍：第一段能否30秒内看出"审题准、观点明"？

## 交稿前分档自评表（打分后再决定是否交付）

完成上面十项自查后，用下表给草稿打分，判断是否真的达到目标区间，而不是凭感觉觉得"应该差不多了"：

| 维度 | 1分（三类卷水平） | 3分（二类卷水平） | 5分（一类下/二类上，达标） |
|---|---|---|---|
| 立意深度 | 观点游离题干或无明确中心论点 | 观点扣题但缺归因层或边界/异化层 | 完成概念界定+归因+边界+升维，立场鲜明且有倾向 |
| 结构完整度 | 段落功能混乱，缺让步段或深掘段，无独立结尾 | 六段骨架基本齐全，但某一段功能薄弱（如让步段仅一句敷衍） | 六段功能清晰，让步-深掘-异化-升维逐层递进，首尾呼应 |
| 语言规范度 | 存在引用幻觉、排例堆砌、口号式结尾，或衔接词/字数明显超限 | 基本规范，个别处冗余、空泛或阐释不足 | 全篇未踩九大通病任何一条，例后阐释到位，衔接自然 |

三项相加后判定：

- **13-15分**：已达62+目标区间，可交付。
- **9-12分**：二类卷水平，需按分低的维度定向返工，不建议直接交付——立意分低回Step 1-2重新审题立意；结构分低回Step 2重排提纲、补齐缺失的段落功能；语言分低回Step 3局部改写，不必推倒重来。
- **≤8分**：建议重新走一遍Step 0-4完整流程，局部修补已经不足以解决问题。

若用户提供的是已有草稿而非新题，本表同样用于判断诊断起点，具体操作转 references/revision-and-upgrade.md。
