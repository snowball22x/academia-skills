# 上海高考高分作文写作 (Shanghai Gaokao Essay, 63+/70)

写作目标定位：**"中规中矩 + 思想深刻"的一类卷下沿作文（63-66分）**。官方细则（议论类）：一类卷63-70，二类上59-62。上海高考语文评卷中心组原组长周宏的阅卷逻辑：先看写什么主题，再看怎么写，且"仅凭立意作为评价标准并不科学，还要看文章层次的推进"——一类卷要求立意深刻且层次推进清晰；二类上留给"有灵气有新意但某一方面有缺陷"或"平稳充实但缺思想深度"的作文。两类作文能上一类卷：中规中矩思想深刻的，与众不同的创新作文。本skill只走第一条路，因为它稳定可复制。评分隐性权重：**立意 > 结构 > 语言**。另须警惕周宏点名的"伪崇高"：毫无铺垫、论据单薄却突然在结尾拔高升华，是阅卷中明确压分的对象——升维必须由前文论证兑现，不允许贴标签式强行升华。

## 任务类型判断（先做，再选流程）

先按用户给了什么来选模式；意图不明时按"是否贴了作文正文 → R；是否出现提纲/思路/怎么写/怎么立意/角度 → O；其余 → W"的顺序判断，仍不确定就问一句，**不要默认成文**。

| 用户给了什么 | 模式 | 读什么 | 终点交付物 |
|---|---|---|---|
| 题目 + 要一篇文章 | **W 成文** | 下方《执行流程》Step 0-4 | 全文 + 证据账本 + 自查结果 |
| 题目 + 要思路 / 审题 / 立意 / 提纲 / 素材 | **O 提纲** | references/mode-outline.md | 审题结论 + 3个立意候选与评估 + 提纲 + 已核验素材清单；**不成文** |
| 题目 + 自己的立意想法（"我想写X角度行不行"） | **O·立意打磨** | references/mode-outline.md 第5节 | 对其立意的评估 + 优化方向 + 替代方案；不替换其立意 |
| 题目 + 标题 + 已写好的作文，要修改/升格/点评 | **R 修改** | references/revision-and-upgrade.md | 默认：诊断报告 + 局部建议；用户明确要求"直接改"才给改稿（标题不动，改动幅度实测） |
| 只有作文、没有题目 | 先问题目；给不出则推断题干并标注"推断" | 同 R | 审题项降级为"待确认" |

四个模式共用同一套底座：证据账本与来源分级（references/search-enhancement.md、assets/evidence-ledger.md）、scripts/check_essay.py、de-template 规则、evidence-bank、assets/past-prompts.md。

## 执行流程（新写流程，严格按顺序，不可跳步）

```
Step 0 能力判断  → 探测两项能力：①网络搜索（有则读 references/search-enhancement.md，按其时机表嵌入搜索动作）；②代码执行（有则可运行 scripts/check_essay.py，无则按文档里的人工清单自查）
Step 1 审题拆解  → 读 references/prompt-analysis.md，完成审题清单（陌生概念/真题：先搜索校准）
Step 2 立意与提纲 → 读 references/structure-and-outline.md，产出提纲；然后盘点素材缺口，**集中搜索核验并填写证据账本**（assets/evidence-ledger.md；成文中途不再搜索）
Step 3 成文     → 读 references/language-and-style.md + references/evidence-bank.md，写全文（库外引用必须搜索核验）
Step 3.5 去模板 → 读 references/de-template.md；有代码执行则 python scripts/check_essay.py write essay.md，只改被标出的句子和段首，最多2轮
Step 4 自查修改  → 先过账本闸门（`check_essay.py claims` 抽取的每个专名/引文/数字都能对上账本，无 dropped 残留）；再用本文件末尾的《交稿前自查清单》逐项核对，并按《分档自评表》打分；若某维度≤2分，回退到对应Step重做（而非在原文上小修），修改后交付
```

每一步的输出（审题结论、提纲）必须先显式写出来再进入下一步，禁止直接一步成文。这是防止"审题浅、平均用力、观点不集中"这一AI最大失分点的核心机制。无搜索能力时跳过Step 0及所有搜索动作，离线流程自足可用。

**违反步骤顺序的常见借口及对策：**

| 借口 | 真相 |
|------|------|
| "题目很简单，审题结论显而易见，可以直接写" | 审题结论写不出来，恰恰说明还没想清楚；30秒内写不出题型判断和中心论点，就还没到能动笔的程度 |
| "先写正文，脑子里想着提纲就行，不用真的写出来" | 隐性提纲会在写作中途漂移，导致平均用力；显性提纲是防漂移的唯一机制 |
| "这道题我见过类似的，可以套用之前的思路直接写" | 每道题的题干关键词和隐含前提不同，跳过Step 1直接套用旧思路正是"答非所问"的成因 |
| "时间紧，先出稿再说，Step 4再补审题结论" | 补写的审题结论是事后合理化，不是审题指导写作；顺序颠倒等于没有审题 |

以上任何一条借口出现，视为违反流程：停止写作，回到Step 1重新开始，而非在成文基础上"回填"审题结论。

## 必须规避的九大AI写作通病（阅卷名师实测反馈）

以下问题是无提示词的LLM在真实阅卷中被扣到50分档的直接原因，写作全程对照规避：

| # | 通病 | 对策（硬性规则） |
|---|------|------|
| 1 | 审题浅、答非所问 | 文章必须直接回应题干的**原始问法**（"必定要…吗""是否""你怎么看"），观点句中复现题干关键词 |
| 2 | 平均用力、观点分散 | 全文只论证**一个中心论点**；分论点必须是中心论点的展开而非并列话题 |
| 3 | 标题烂俗或空泛 | 禁用"破茧成蝶""扬帆起航"类意象；标题必须内含观点或核心概念关系，且题眼在正文中兑现 |
| 4 | 小标题式/论文腔结构 | 禁用小标题、序号分节；用过渡句衔接；避免"首先/其次/再次"式机械推进 |
| 5 | 中间大两头小、无结尾 | 首段≤150字快速入题亮观点；必须有独立结尾段，回扣题干+升华 |
| 6 | 案例堆砌、例证裸奔 | 每段最多1-2个例子，**例后必须有≥2句阐释**将例子绑定回论点；排例（三个以上连用）全文至多一处 |
| 7 | 引用幻觉、张冠李戴 | 只使用 references/evidence-bank.md 中已验证的引证；不确定出处的名言一律改为转述或删除 |
| 8 | 只正面阐释、缺深掘 | 必须包含"为什么"层（归因）和"边界"层（该观点被推向极端后的异化），单向度赞美/批判直接掉到二类中 |
| 9 | 衔接词滥用、机械转折 | "然而""但是"每篇≤3次；改用让步式过渡（承认对方合理处，再划出其边界）和设问式过渡；具体措辞每篇换，见 references/de-template.md |

## 核心写作范式（速览）

上海卷全部为思辨性材料作文，五种题型（识别方法见 references/prompt-analysis.md）：

| 题型 | 特征 | 例 |
|------|------|-----|
| A 设问质疑型 | "仅仅/必定/是否…吗？" | 2023好奇心、2025专转传 |
| B 观点评价型 | "有人说…，也有人认为不尽如此" | 2021时间的沉淀 |
| C 概念阐释型 | "谈谈你对X的认识和思考" | 2024认可度 |
| D 关系思辨型 | A与B的关系/张力 | 2026科技与想象 |
| E 寓言设喻型 | 材料为寓言、比喻或自然现象类比 | 26二模青浦丑小鸭、"知识的岛屿" |

所有题型共用一副**思辨五段骨架**（详见 references/structure-and-outline.md）：

1. **引论**：现象切入 → 概念界定 → 亮明中心论点（直接回应题干问法）
2. **正论/让步**：承认题干观点（或某一方）的合理性，说明它回应了什么真实需求
3. **驳论/深掘**：揭示其局限、隐含前提的问题、被极端化后的异化
4. **整合/升维**：重新界定概念，提出"真正的/成熟的X"，建立动态统一
5. **结语**：方法论收束 + 回扣题干关键词 + 联系时代与青年（落在具体认知姿态，不喊口号）

三个不可妥协的思维动作：**概念界定**（用"不是A，而是B"的排除式定义）、**让步论证**（先承认对方合理性再指出边界）、**主体性落点**（结尾回到人的主动选择权）。

## 硬性格式要求

全文900-1000字（安全区间，题目要求"不少于800字"）；自拟标题；纯议论文，不写记叙文、书信体、小标题体；简体中文；不分点罗列，全部以连贯段落行文；段落数6-8段。有代码执行时，成文后必须运行 `python scripts/check_essay.py write essay.md` 实测字数（含/不含标点两种口径，正文不含标题），而不是估算；不具备代码执行时，按分段字数配额估算（见language-and-style.md第8节）。

## 交稿前自查清单（Step 4，逐项核对）

1. 观点句是否在第一段末出现，且直接回答了题干的原始问法？
2. 全文是否只有一个中心论点，每个分论点都服务于它？
3. 是否完成了概念界定（且用了排除式定义）？
4. 是否有让步段（承认对方合理性）？是否有归因层和边界/异化层？
5. 每个例子后是否有≥2句阐释？是否存在三例连排超过一处？
6. 所有引文是否都来自evidence-bank、经搜索核验、或确凿无疑？删除任何存疑引用；具体数字与作品归属是否已核验？
7. 标题是否含观点/概念，题眼是否在正文至少出现两次？
8. 结尾段是否回扣题干关键词并落在"人"的主体性上？
9. "然而/但是"是否≤3次？有无小标题、序号、分点？
10. 字数是否在900-1000字？有代码执行则 check_essay.py 实测并确认无 HARD 项；否则逐段估算（不足则加厚阐释而非加例子）。
11. 口头禅（更值得警惕的是/诚然/归根结底/由此看来）是否各≤1次？连接词开头的段落是否≤3个？破折号≤2？（见 de-template.md）

自查发现问题必须修改后再交付。若时间允许，模拟阅卷人视角通读一遍：第一段能否30秒内看出"审题准、观点明"？

## 分档自评表（打分制，量化"离62分还差多少"）

打分前先做一次**对抗性复核**：假设自己是一名倾向给低分的阅卷人，专找茬——

- 针对立意深度：追问"归因层是否只是换个说法重复现象，边界层是否真的推到了极端"？
- 针对结构完整度：追问"是否有一段读起来像在完成任务、凑字数，而非真正推进论证"？
- 针对语言规范度：追问"如果通篇删掉本篇独有的题干关键词，这段话能不能原样套到任何一道思辨作文题上"？——能套用即说明论证空泛，立意深度分不得高于2分。

用这个挑刺后的印象打分，而非写完时的自我满意度。完成自查清单和对抗性复核后，用下表给全文打分，三项各1-5分（5分最高）：

| 维度 | 1-2分（明显不足） | 3分（及格） | 4-5分（达标） |
|------|------|------|------|
| 立意深度 | 只有正面阐释，无归因/边界层；或跑题、观点分散 | 有让步+深掘，但异化分析单薄 | 归因、边界、异化三层俱全，整合段有明确倾向 |
| 结构完整度 | 五段骨架缺2环以上；无独立结尾或首段过长 | 骨架齐全但某段功能不清晰 | 六段各司其职，段间过渡自然，首尾均衡 |
| 语言规范度 | 排例超限、引用存疑、"然而"滥用、有小标题 | 无硬伤但表达平淡、题眼复现不足 | 无硬伤、题眼呼应清晰、句式有变化 |

判分规则：
- 三项总分≥12分且无单项≤2分 → 达到63+目标，可交付。
- 任一维度≤2分 → 明确回退：立意深度低分回Step 2重新立意与提纲；结构完整度低分回Step 2补骨架；语言规范度低分回Step 3局部改写，不必推倒重来。
- 总分9-11分（无≤2分项）→ 属于二类中区间，按权重"立意>结构>语言"顺序，先补最低分维度再交付。
